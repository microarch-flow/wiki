# 为什么 HBM 逼着产业走向 2.5D 和 3D

上级：[[00 - 先进封装 Wiki 索引]]

相关：[[04 - Si Interposer]]、[[07 - TSMC 先进封装地图]]、[[08 - 3D IC]]、[[18 - CoWoS-S、CoWoS-R、CoWoS-L 的真正差别]]

## 先给结论

HBM 之所以逼着产业走向 2.5D 和 3D，不是因为“HBM 比 GDDR 更新”，而是因为它从一开始就是：

- 通过垂直堆叠提升容量密度
- 通过超宽总线提升总带宽
- 通过更短互连降低每比特功耗

而要把这些优势真正交到 logic die 手里，就必须依赖比传统 PCB / package substrate 更高密度、更短距离的封装互连平台。

一句话：

`HBM 不是普通存储芯片，而是把“存储器问题”直接变成了先进封装问题。`

## 1. 为什么传统外部内存方案不够了

如果用传统外部内存方案，比如较长板级走线、较高频率串行通道，想继续把带宽做上去，会遇到几个硬限制：

- I/O 数量上不去
- 走线太长，功耗和寄生变差
- 频率继续拉高，SI/PI 越来越难
- 封装与板级面积压力越来越大

所以产业开始转向另一条路：

`不是无限拉高单根线速率，而是通过更近距离、更多并行 I/O、系统级封装，把总带宽堆起来。`

HBM 就是这条路线的代表。

## 2. HBM 的本质是什么

HBM 不是“单颗很快的 DRAM”，而是：

- 多层 DRAM die 垂直堆叠
- 通过 TSV 互连
- 再通过超宽接口与 logic die 近距离相连

这意味着 HBM 本身已经是 3D memory stack。

所以当系统要用 HBM 时，至少已经天然带入了两层封装/集成复杂度：

1. memory stack 内部的垂直堆叠
2. memory stack 与 logic die 之间的高密度横向互连

## 3. 为什么 logic 和 HBM 必须靠得很近

因为 HBM 的价值不是单颗 memory stack 自己跑得快，而是：

- logic die 能以极高总带宽访问它
- 每比特功耗还不能失控

要做到这一点，logic-to-HBM 的连接必须：

- 足够短
- 足够宽
- 具有更低寄生
- 能维持更好的 PI / SI

这正好把系统推向：

- Si interposer
- RDL interposer
- local silicon interconnect
- 更进一步的 3D 集成

## 4. 为什么 2.5D 特别适合 HBM

2.5D 本质上是在平面上把：

- logic die / chiplet
- HBM stacks

放到高密度互连平台上。

这种方式的好处是：

- HBM 不必贴得很远
- routing density 足以承接超宽总线
- 比传统 substrate 更容易做高带宽互连
- 还能在系统层面协调 PI / SI / 热

所以今天大部分高端 AI/HPC 的 logic + HBM 封装，首先会走 2.5D，而不是普通 FC-BGA。

## 5. 那为什么还要继续往 3D 走

因为 2.5D 虽然已经解决了很多问题，但随着：

- HBM 数量继续增加
- logic die 功耗继续变大
- 总带宽要求继续上升
- package 尺寸继续变大

系统又会面临新的瓶颈：

- 横向距离仍不够短
- 大面积 interposer / RDL 平台越来越难做
- PI / SI / 热 / warpage 越来越难控

于是行业继续看向 3D：

- 更短的垂直互连
- 更低的 power-per-bit
- 更高的带宽密度
- 更小的系统 footprint

## 6. 这件事为什么对台积电特别有利

因为台积电正好同时有：

- CoWoS 这类 2.5D 平台
- SoIC 这类 3D 平台
- 先进逻辑 foundry

HBM 的系统需求把前端逻辑、2.5D 封装、3D 堆叠和系统热设计绑在一起，而台积电恰好把这几块平台化了。

这也是为什么在 AI/HPC 时代，HBM 的爆发会直接强化台积电在先进封装上的地位。

## 7. 一个更工程化的理解

如果没有 HBM，很多系统可以继续容忍：

- 更长的外部存储互连
- 更低密度的封装平台
- 普通 substrate + board-level 优化

但一旦上 HBM，系统需求会马上变成：

- I/O 非常多
- 功耗预算非常紧
- 延迟敏感
- 热集中
- 封装与供电一体化要求更高

所以 HBM 不是“给先进封装加分”，而是直接把先进封装变成必答题。

## 8. 最终压缩理解

`HBM = 3D memory stack + 超宽近距 logic 接口`

因此：

- memory stack 内部天然需要 3D
- memory stack 与 logic 集成天然推动 2.5D
- 当系统继续追求更高带宽/更低功耗时，又进一步推动 3DIC 演进
