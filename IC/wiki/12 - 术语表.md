| Die | 从晶圆切割出的裸芯片 |
| Package | 封装后的芯片器件 |
| Substrate | 封装基板 |
| Interposer | 中介互连层 |
| RDL | Redistribution Layer，重布线层 |
| TSV | Through-Silicon Via，硅通孔 |
| Micro-bump | 微凸点互连 |

| HBM | High Bandwidth Memory，高带宽存储 |
| Chiplet | 芯粒 |
| DTC | Deep Trench Capacitor，深沟槽电容 |
| PI | Power Integrity，电源完整性 |
| SI | Signal Integrity，信号完整性 |
| CTE | Coefficient of Thermal Expansion，热膨胀系数 |
| Warpage | 翘曲 |
