## 这页的作用

这页不是新增知识，而是把前面已经建立起来的四层东西拉平：

- 路线
- 平台
- 公司
- 失效模式

它的目的就是让你以后复习、写分析或做横向比较时，不必在几十篇笔记里来回跳。

## 1. 路线 -> 平台 -> 公司 总映射

| 路线 | 代表平台 | 代表公司/体系 | 最典型场景 |
| --- | --- | --- | --- |
| Si Interposer | CoWoS-S、I-CubeS | TSMC、Samsung | AI/HPC、logic + HBM |
| RDL / Fan-out | InFO-oS、FOCoS、S-SWIFT、XDFOI | TSMC、ASE、Amkor、JCET | mobile、networking、多 chiplet |
| Embedded Bridge | EMIB、FOCoS-Bridge、S-Connect、I-CubeE | Intel、ASE、Amkor、Samsung | 局部高密度 D2D、chiplet 系统 |
| 3DIC | SoIC、Foveros Direct、X-Cube | TSMC、Intel、Samsung | 高密度垂直堆叠、cache-on-logic |

## 2. 平台 -> “为什么会选它” 总对照

| 平台/路线 | 现实里为什么会选它 |
| --- | --- |
| Si Interposer | HBM 接口太宽、局部密度要求太高、性能优先级最高 |
| Fan-out / RDL | 想要比 substrate 更强、比 full silicon interposer 更现实的成本和尺寸折中 |
| Embedded Bridge | 局部需要极高密度，但不想全局都上大硅平台 |
| 3DIC / Hybrid bonding | 想进一步压缩连接长度、提升带宽密度和 power-per-bit |
| CoWoS-S | 最强 logic + HBM 互连和 PI 支撑 |
| CoWoS-R | 大尺寸、机械平衡和成本更重要 |
| CoWoS-L | 局部极高密度 + 全局大平台的折中最优 |

## 3. 路线 / 平台 -> “它最怕什么” 总对照

| 路线/平台 | 最怕什么 |
| --- | --- |
| Si Interposer | 大尺寸硅平台的成本、良率、warpage、热机械耦合 |
| Fan-out / RDL | die shift、RDL stress、多层 build-up 后 cracking、warpage |
| Embedded Bridge | 局部桥区与外围平台过渡、系统协同复杂度 |
| 3DIC | 热、CTE mismatch、warpage、测试前移 |
| CoWoS-S | 大硅平台继续放大后的成本与 warpage 压力 |
| CoWoS-R | 极限局部密度不够 |
| CoWoS-L | 系统折中太复杂，局部/全局分工如果切不好收益不够 |
| Micro-bump | pitch 上限与 bump fatigue |
| Hybrid bonding | 平坦度、洁净度、对位、薄 die handling、bonding defect |

## 6. 如果你现在要分析一个新平台，建议固定问这 6 个问题

1. 它属于哪条路线？
2. 它更像哪家公司的哪种平台？
3. 它为什么会被选中，而不是别的路线？
4. 它最怕什么？
5. 它最容易出哪类失效？
6. 它在量产深度上处在哪一层？

## 7. 最后的压缩结论

如果把整套 advanced packaging 知识压成一句话，就是：

`路线决定结构，平台决定实现方式，公司决定量产能力，失效模式决定这条路能不能真正跑通。`
