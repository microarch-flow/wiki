## 这页的作用

这页不是为了列一长串公司名，而是为了建立一个问题框架：

`当你研究一家企业时，先把它放回先进封装供应链的哪一层。`

## 1. 先进封装企业可以先分成 8 类

### 1. 系统需求方

典型包括：

- AI GPU / AI ASIC 厂商
- CPU / networking / mobile SoC 厂商
- 云服务厂商

它们决定：

- 是否需要 HBM
- 是否走 chiplet
- 是否值得上 2.5D / 3D

### 2. 先进逻辑 foundry / IDM

这类公司决定：

- logic die 从哪里来
- 能否与先进封装深度协同

### 3. Memory / HBM 厂

这类公司决定：

- HBM stack 能否供应
- HBM 代际和堆叠能力

### 4. OSAT / advanced packaging 厂

这类公司决定：

- assembly 能力
- fan-out / 2.5D / 3D 平台
- 测试与可靠性能力

### 5. 基板 / 载板厂

这类公司决定：

- 高端 substrate 的供给上限
- 大尺寸 package 的系统承载能力

### 6. 材料厂

这类公司决定：

- RDL 材料
- underfill / mold / adhesive
- bump / bonding / thermal 材料

### 7. 设备厂

这类公司决定：

- TSV / RDL / bonding / test 工艺窗口能否稳定打出来

### 8. EDA / 设计生态厂商

这类公司决定：

- package co-design
- PI / SI / thermal / mechanical 仿真
- chip-package-system 协同设计效率

## 2. 研究一家企业时最好固定问 6 个问题

1. 它处在哪一层？
2. 它是平台型玩家还是单点能力玩家？
3. 它的能力是通用封装能力，还是 AI/HPC 级能力？
4. 它的强项是设计、制造、材料、设备还是测试？
5. 它的能力已经量产，还是还在平台建设期？
6. 它和谁耦合最强？

## 3. 一个简单的企业研究模板

### 公司定位

- 属于哪一层
- 面向哪些应用

### 技术抓手

- 2.5D / 3D / fan-out / bridge / testing / materials / substrate 等

### 当前阶段

- 平台概念
- 工程导入
- 稳定量产
- 高端主战场量产

### 核心短板

- 规模
- 良率
- 供应链配套
- 客户生态

## 6. 如何读这张矩阵

### TSMC、Intel、Samsung

这三者的共同点是：

- 都不只是 assembly 厂
- 都把前端逻辑和 advanced packaging 强耦合

区别在于：

- TSMC 的对外 foundry + packaging 生态最强
- Intel 的 3D / bridge 路线特色很强
- Samsung 在 I-Cube / X-Cube 上也形成了完整家族

### ASE、Amkor

这两者代表的是：

- 顶级 OSAT 也可以把 advanced packaging 做到很强
- 但它们与最先进逻辑 foundry 的协同方式不同于 TSMC

### JCET、Tongfu、Huatian

这三者代表的是大陆 advanced packaging 追赶的主平台。  
其中：

- JCET 的公开平台表达最完整
- Tongfu 在高性能处理器类封装经验上值得重点关注
- Huatian 则更像持续往上推 2.5D/AI 封装平台的追赶者
