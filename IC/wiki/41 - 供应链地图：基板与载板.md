## 为什么基板是核心平台

在普通理解里，基板像“下面托着的板”。  
但在高端先进封装里，基板其实决定很多上限：

- I/O 引出能力
- 供电网络
- 机械支撑
- warpage 表现
- 大尺寸 package 可实现性

## 1. 基板在系统中的角色

可以把它理解成：

- 上接 interposer / RDL / module
- 下接 board / system

所以它是：

`高密度局部平台和更大系统平台之间的桥梁。`

## 2. 高端基板最难的地方

- 层数高
- I/O 多
- 电流大
- 高频信号损耗敏感
- 尺寸越大越难控 warpage

## 3. 为什么先进封装越往上，越容易卡在基板

因为当上层平台越来越强时：

- logic + HBM 越来越多
- 封装尺寸越来越大
- 电源和信号要求越来越严

最后很容易发现：

- interposer 能做
- HBM 能放
- 但基板承不住整个系统需求

这就是为什么基板经常成为 AI/HPC 封装上限的一部分。
