# 大陆先进封装供应链现状

上级：[[00 - 先进封装 Wiki 索引]]

相关：[[03 - 技术路线总览]]、[[07 - TSMC 先进封装地图]]、[[14 - 为什么台积电领先先进封装]]、[[20 - 大陆先进封装：材料、基板、设备分别卡在哪]]

## 先给结论

截至 **2026-05-04**，大陆先进封装供应链不能简单概括成“没有”或“已经完全打通”，更准确的判断是：

### 已经比较强的环节

- OSAT 制造基础
- FC、WLP、Fan-out、SiP、Bumping
- 大尺寸多芯片封装经验
- 部分 Chiplet 平台和 2.5D 路线

### 正在往上冲的环节

- RDL-based Chiplet
- Si interposer 2.5D
- 大尺寸 AI/HPC 封装
- 板级/面板级先进封装

### 仍有明显短板的环节

- 对标 TSMC CoWoS 的超大规模 logic + HBM 高良率量产
- 最先进 3DIC / hybrid bonding 产业化深度
- HBM 本体供应
- 顶级 ABF / 高端 substrate 生态
- 与 leading-edge foundry、EDA、HBM、测试和客户生态的系统闭环

一句话：

`大陆先进封装已经不是“起步阶段”，但距离台积电在 AI/HPC 级 2.5D/3D 封装上的系统能力，仍有明显代差。`

## 1. 不要把“先进封装”看成一个单点

大陆供应链现状必须拆成几层看：

1. OSAT 制造能力
2. 工艺平台能力
3. 材料与基板能力
4. HBM / memory 配套能力
5. 设计与仿真生态
6. 大客户量产导入能力

只有这几层一起打通，才能真正做出高端 AI/HPC 封装。

## 2. 大陆封测厂的现阶段位置

### 长电科技（JCET）

从公开资料看，长电是大陆在先进封装里最值得重点看的公司之一。

公开信息显示：

- XDFOI Chiplet 已进入稳定量产
- 覆盖 2D、2.5D、3D 集成技术
- 面向 HPC、AI、HBM 等方向
- 公司公开提到 RDL、硅转接板、硅桥等多样化路径

更具体地说，长电现在的强项是：

- 基于 fan-out / RDL 的高密度异构集成
- 面向 Chiplet 的封装与测试一体化
- OSAT 级高量产组织能力

但如果拿它去直接对标台积电 CoWoS 的最难场景，仍要注意两点：

- 公开资料能证明其先进平台在量产推进，但不等于已经达到 TSMC 同等级 logic + HBM 超大封装规模
- 它更像是大陆最有希望在高性能先进封装上继续往上爬的 OSAT 平台之一

### 通富微电（Tongfu）

通富的公开表达相对分散，但可以确认几点：

- 较早就建设 2.5D/3D 高端产线
- 已在 Chiplet、2.5D/3D 方向持续布局
- 与 AMD 关系深，具备高性能处理器类封装经验

从公开信息看，通富更像：

- 在大尺寸多芯片封装和高端 FCBGA/MCM 上有实战经验
- 正往更高阶的 Chiplet / 2.5D / 3D 平台推进

但它的公开披露不像 TSMC/Intel 那样把完整封装路线和量产层次讲得非常细，所以对其最前沿能力判断应保守一些。

华天近两年的信息很明确，重点是：

- 持续推进先进封装技术与产品研发
- 完成 2.5D 产线建设和设备调试

## 3. 从技术路线看，大陆走到了哪一步

### 3.1 Fan-out / RDL

这是大陆相对更有机会的方向之一。

原因：

- OSAT 起家，后道组织能力强
- 不必完全依赖整块大硅 interposer
- 更容易从既有 WLP / FO / FC 经验继续演进

长电的 XDFOI 就是这一类路线的代表。它本质上不是简单复制 CoWoS-S，而是尝试用 RDL / fan-out / chiplet 体系形成自己的高密度异构集成平台。

### 3.2 Si interposer 2.5D

这条路大陆也在推进，但难度显著更高。

原因在于它同时卡住：

- TSV
- 大面积硅 interposer
- 细 pitch routing
- 大封装 warpage
- HBM 邻近 PI / SI / 热设计

华天年报里已经明确提到基于 Si interposer 的 2.5D 封装研发与平台转化，这说明产业方向已经很明确；但要做到类似 CoWoS 的产业化深度，还需要时间。

### 3.3 bridge / local silicon interconnect

这类路线对大陆反而有现实吸引力，因为它不像 full interposer 那样要求整块大硅全部做到极致，而是：

- 关键区域用硅
- 外围继续用 RDL / substrate

如果未来大陆在 substrate、RDL、局部硅桥加工和多芯片 assembly 上持续进步，这条路线很可能比“直接复制最强版本 CoWoS-S”更有现实性。

### 3.4 3DIC / hybrid bonding

这仍然是更难的一层。

原因不只在 bonding 本身，还在整套系统：

- surface planarity
- Cu / dielectric 界面控制
- 超细 pitch 对位
- 薄 die handling
- 热应力与可靠性
- KGD 和测试

从公开公司资料看，大陆企业普遍会写到 2.5D/3D、Chiplet、TSV、WLP、Fan-out 等布局，但真正像 TSMC SoIC / Intel Foveros Direct 这样把 3DIC 作为成熟外部平台大规模展开，公开证据仍然有限。

## 4. 大陆供应链真正的短板不只在封测厂

这是最容易被忽略的一点。

很多人一说“先进封装差距”，就只盯着 OSAT；其实真正难的是配套链条。

### 4.1 HBM 供应

今天最难的 AI/HPC 封装，很多都绕不开 `logic + HBM`。

而 HBM 不是普通 DRAM，它涉及：

- TSV memory stacking
- memory die thinning
- 高速 PHY / controller 协同
- 封装与测试协同

大陆在这一层仍然明显偏弱，这会直接限制“类 CoWoS AI 封装”的上限。

### 4.2 高端 substrate / ABF

大封装、高 I/O、高速信号和高电流供电，都要求非常强的 substrate 体系。

这块如果不能稳定拿到足够高水平的平台，封装再往上走会被卡住。

### 4.3 设计生态

先进封装不是“工厂做好就行”，还要有：

- package co-design
- 3D / 2.5D 设计工具
- HBM / D2D IP
- SI / PI / thermal 仿真

这类生态差距，往往比单项设备差距更难补。

### 4.4 leading-edge logic foundry 协同

台积电的优势之一，是把最先进逻辑制程和先进封装放在一个 foundry 体系里协同。

大陆目前更强的是后道封测组织能力，但在“最先进逻辑晶圆 + 先进封装 + HBM + 生态”这个全链条耦合上，还不具备同等级闭环。

## 5. 所以该怎么评价大陆现状

更准确的分层判断如下。

### 第一层：不是空白

大陆在：

- FC
- WLP
- FO
- SiP
- bumping
- TSV
- Chiplet 封装

这些环节已经有相当基础，不应再用“完全不会做”去描述。

### 第二层：已经有先进封装平台雏形

以长电、通富、华天为代表，已经出现：

- RDL-based Chiplet 平台
- 2.5D/3D 产线建设
- 面向 AI/HPC 的先进封装导入

这说明大陆不是只停留在传统封装。

### 第三层：和台积电的差距主要在“最高难度量产”

如果目标是：

- 多颗 logic chiplet + 多颗 HBM
- 超大面积 interposer / bridge / RDL interposer
- 高良率大规模量产
- 完整 foundry + packaging + ecosystem 协同

那差距仍然明显。

## 6. 一个更稳妥的最终结论

如果写进 wiki，建议用这段话：

> 截至 2026-05-04，大陆先进封装供应链已经在 FC、WLP、Fan-out、SiP、Bumping、Chiplet 封装以及部分 2.5D/3D 平台上形成了较强基础，长电、通富、华天等企业都在向高性能先进封装持续推进。  
> 但如果目标是对标台积电 CoWoS / SoIC 所代表的 AI/HPC 级最难场景，即大规模 logic + HBM、超大封装、高良率量产以及完整 foundry-EDA-HBM-测试生态协同，大陆目前仍处于追赶阶段。  
> 因此，大陆现状更适合描述为“中高端先进封装能力快速提升，部分平台已量产或接近量产，但在最高端 2.5D/3D 系统能力上仍有明显差距”。
