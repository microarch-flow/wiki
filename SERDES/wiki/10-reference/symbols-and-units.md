# 符号、单位和参考面

上级：[SerDes 术语、资料与自测](./README.md)

本页汇总已编写章节的常用量。公式必须与观察方向、测量位置、时间窗口和具体协议匹配；变量名称只是本专题的约定。

## 速率与时间

| 量 | 定义 / 单位 | 条件与注意事项 |
| --- | --- | --- |
| 符号率 `R_sym` | 每 lane 每秒发送的符号数，`Bd` | `GBd = 10^9 Bd`。它不是任意并行时钟频率。 |
| 每符号比特数 `b` | 本例 NRZ 为 1，PAM4 为 2 | 指调制映射输入的线路比特，不自动等于有效载荷比特。 |
| UI | 在本专题示例中为 `1 / R_sym` | `10 GBd` 对应 `100 ps`；实际标准的测量定义需另查。 |
| 线速率 | `R_sym × b`，`bit/s` | 按单 lane、单方向表示；协议、控制、编码和 FEC 口径应单独写明。 |
| 指定口径的数据上限 | `R_sym × b × lane 数 × η`，`bit/s` | `η` 包含哪些开销必须明确；仅在 lane 持续可用且对应假设成立时适用。 |
| 传输时间 | 在该速率独占持续服务下，`T = 8L / R_eff` | `L` 的单位为有效 byte，`R_eff > 0`，并须避免重复计算开销。 |

本专题的 `GB/s` 使用 `10^9 byte/s`；`GiB/s` 使用 `2^30 byte/s`。`GT/s` 表示每秒传输次数，不能不看该接口的调制和编码就直接换成应用吞吐。[速率与时钟](../01-overview/rates-clocks-and-ui.md)、[带宽与能耗](../05-signaling-and-metrics/bandwidth-power-efficiency.md)

## 电气、误码与能耗

| 量 | 定义 / 单位 | 条件与注意事项 |
| --- | --- | --- |
| 差模与共模电压 | `Vdiff = VP − VN`，`Vcm = (VP + VN)/2`，单位 V | 两者必须在同一时刻、同一参考面取值。 |
| 传输增益 | `20 log10(|Sdd21|)`，单位 dB | 指给定端口、参考阻抗和频率的差分 S 参数；正的插入损耗量与负的传输增益写法需分辨。 |
| BER 观察比值 | 错误比特数 / 已检查比特数 | 写明观察位置、码型、FEC、时间和计数规则；未检查数据不能算入分母。 |
| 零错误置信上界 | `1 − 0.05^(1/N) ≈ 2.996/N` | 仅在 `N` 个独立同分布比特、错误概率恒定、零观察错误时，为单侧 `95%` 上界。 |
| 平均功率与能量 | `E = Σ(P_i × T_i)`，`P_avg = E / T_window` | 状态应互斥或明确功率分摊；窗口需完整。 |
| 每交付比特能耗 | `E / B_delivered`，通常用 `pJ/bit` | 分子和分母使用同一窗口与边界；零交付比特时该比值未定义。 |

光功率 `dBm` 是相对 `1 mW` 的对数功率单位。光功率比的 dB 用 `10 log10(P2/P1)`；电压比的 `20 log10` 用法还依赖对应参考条件。电通道某频点的 S 参数和光接收功率不是同一观察量，不能直接混作完整预算。[CPO 案例](../08-system-applications/cpo-electrical-optical.md)

参考面是定义输入或测量位置的边界。比较两份结果时，还要核对端口、去嵌、温度、噪声、测试方式和单位；只比较数值可能得出错误结论。
