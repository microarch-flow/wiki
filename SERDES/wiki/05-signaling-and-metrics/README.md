3. [怎样理解眼图和抖动？](./eye-and-jitter.md)
4. [BER、置信度与 FEC 怎样关联？](./ber-confidence-and-fec.md)
5. [怎样计算带宽和每比特能耗？](./bandwidth-power-efficiency.md)
