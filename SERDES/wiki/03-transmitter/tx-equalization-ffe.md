# 发送均衡与 FFE：为什么要改变发送波形？

上级：[发送端](./README.md)

某些通道对不同频率的衰减不同，导致一个符号的响应影响其他采样时刻。TX 均衡在发送侧改变波形，尝试改善通道后的判决余量。它依赖目标通道和接收条件；更强的均衡不一定更好。

## 两个抽头的教学例子

设当前与上一符号 `a[k]`、`a[k−1]` 均为 `−1` 或 `+1`，使用归一化公式：

`y[k] = a[k] − 0.25a[k−1]`。

| 上一符号 | 当前符号 | 输出 `y[k]` |
| ---: | ---: | ---: |
| `−1` | `+1` | `+1.25` |
| `+1` | `+1` | `+0.75` |
| `+1` | `−1` | `−1.25` |
| `−1` | `−1` | `−0.75` |

这个例子中，跳变后的符号幅度较大，连续同号的幅度较小。第一个输出必须约定更早的历史状态。系数、符号和输出范围只是教学假设，实际电路还要满足摆幅、线性和供电约束。

FFE（前馈均衡器）可由多个带权抽头构成。抽头的具体命名与符号约定要以实现为准。它可与驱动级结合；也可能在接收侧出现。[AMD 的收发器说明](https://docs.amd.com/api/khub/documents/qoVxLVymW4dP6eFnjYnZCA/content)给出了指定 TX 的 FIR 去加重实例。

## 与教学通道串接

假设上面的 `y[k]` 是通道输入，通道在采样时刻满足 `r[k] = 0.7y[k] + 0.2y[k−1]`。代入得到：

`r[k] = 0.7a[k] + 0.025a[k−1] − 0.05a[k−2]`。

与不使用 FFE 时的历史项 `0.2a[k−1]` 相比，这组假设把一个历史项的系数降为 `0.025`，但同时引入了更早符号的 `−0.05` 项。这里假设线性时不变、符号间隔和采样时刻固定，也忽略摆幅裁剪。它说明均衡是在整个响应上做取舍，不证明真实链路已经达标。

## 代价与边界

提升相对高频分量或压低低频分量会改变输出能量分配。若过度补偿，通道后的波形可能更差，也可能超出驱动摆幅或线性范围。FFE 不能保证消除噪声、串扰和所有反射；参数需要在目标通道及接收器条件下评估。
