# 怎样阅读公开的 SerDes 产品声明？

上级：[系统应用](./README.md)

产品页面可以帮助确定候选方案，但“最高速率”“支持某协议”或“零错误”都需要边界。阅读时先记录厂商、产品、工艺、页面日期 / 访问日期、工作模式与数据来源，再把结论分成厂商声明、可复算结果和待核实项目。

## 一个公开页面的阅读练习

以 [Synopsys 224G Ethernet PHY IP 页面](https://www.synopsys.com/designware-ip/interface-ip/ethernet/224g-ethernet-phy-ip.html)为例，页面描述了支持 PAM4 和 NRZ 的 PHY，以及包含模拟前端、ADC 和 DSP 的接收路径；页面还标称支持 `+45 dB` 通道损耗并展示零 post-FEC BER。这里记录的是**厂商公开声明**，不是本 Wiki 的独立测量。访问日期：`2026-11-11`。

如果一个示例信号的**线路比特率精确为** `224 Gb/s`，且使用 PAM4 的每符号 `2 bit`，则可计算符号率 `112 GBd`，一个 UI 约 `8.93 ps`。这是基于题设的换算；产品名称里的“224G”不能单独确定所有运行模式的精确速率、净载荷或时钟频率。

| 页面或报告中的项目 | 继续追问 |
| --- | --- |
| 通道损耗 | 频率、差分参考面、参考阻抗、封装是否包含在内？数值是正的损耗量还是负的传输增益？ |
| 误码或眼图 | pre-FEC 还是 post-FEC？检查多少比特、什么码型和条件？是仿真、测试芯片还是系统测量？ |
| 工艺与功耗 | 对应哪个工艺、供电、温度、lane 配置？是否包含共享 PLL、数字逻辑与 FEC？ |
| 协议与互通 | 宣称支持哪些版本与模式？是否有对应项目的合规记录，以及哪些对端和条件下的互通数据？ |
| 产品状态 | 是设计目标、仿真、样片、客户导入还是量产证据？页面何时更新？ |

上表的问题不意味着该产品缺少这些能力。仅凭公开页面中看到的概述，无法独立确认全部测试条件、样本覆盖与长期结果；“零 post-FEC BER”的表述也不能直接理解为真实误码概率为零。应向供应商取得适用版本的详细资料。数据表可能变化，引用时应重新核验。
