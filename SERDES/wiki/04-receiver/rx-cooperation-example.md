# 走一遍 RX 协同案例

上级：[接收端](./README.md)

本例沿用专题的单向 `10 Gb/s` NRZ 链路，假设发送端 FFE 旁路。它是归一化的采样点模型，用来说明关系，不是电路仿真或实测。

## 从通道到判决

令当前发送符号为 `+1`，上一符号为 `−1`。在正确采样时刻，通道模型给出：

`r = 0.7 × (+1) + 0.2 × (−1) = +0.5`。

1. 前端接收信号。实际 CTLE 可根据通道调整频率响应；本例未给出其完整响应，因此不把它代入这条抽样等式。
2. 假设 CDR 已使采样时刻满足模型条件。若采样时刻改变，这里的 `0.7`、`0.2` 未必仍适用。
3. 假设 DFE 的上一判决正确，且系数为 `0.2`，修正值为 `+0.7`。若旁路 DFE，样本仍为 `+0.5`。
4. 在零门限、无噪声的假设下，两种情况都判为 `+1`。无论是否判对，仍需按约定位序和边界解串。

再把 `0xB2000000` 的前四位 `1011` 放进同一模型。映射为 `+1, −1, +1, +1`，并假设第一个符号之前的历史为 `−1`。四个通道样本依次为 `+0.5, −0.5, +0.5, +0.9`。若历史判决及系数都正确，理想 DFE 输出依次为 `+0.7, −0.7, +0.7, +0.7`；零门限判决得到 `1011`。这是四个符号的手算，尚未收满一个 32 bit 字。

## 这没有证明什么

例子没有模拟连续波形、CTLE 全频响、CDR 闭环、器件非线性、随机噪声、误码统计或 PVT。它说明历史项和判决之间的因果关系，不能证明某产品、RTL 或物理链路能够工作。

如果要验证一个实际接收器，还需要明确输入参考面、码型、通道、工作点、时钟、测试时长和错误指标。后续章节进一步讨论[信号与指标](../05-signaling-and-metrics/README.md)、[初始化与链路训练](../06-link-operation/README.md)，以及[设计与验证](../07-design-and-validation/README.md)的证据边界。
