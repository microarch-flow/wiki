## 这页在回答什么问题

这页回答：每个公司/产品案例在本 wiki taxonomy 下应该如何归类，以及它说明了哪类商业化门槛。

| 卡片 | 本章分类 | 读法 |
| --- | --- | --- |
| [Mythic](cim-companies-mythic.md) | CIM | Flash-based analog CIM，重点看 analog 产品化和公司路线重启 |
| [Axelera](cim-companies-axelera.md) | CIM | SRAM-based digital CIM，重点看标准 CMOS、SDK 和可购买 form factor |
| [Samsung HBM-PIM](pim-companies-samsung-hbm-pim.md) | PIM | HBM memory bank 内 compute，重点看 memory vendor 生态 |
| [SK hynix AiM/AiMX](pim-companies-sk-hynix-aim.md) | PIM | GDDR6 memory chip compute + card demo，重点看 prototype 到部署距离 |
| [UPMEM](nmc-companies-upmem.md) | NMC 对照 | DIMM/server 近数据平台，重点看 host+DPU 编程和部署边界 |

每张卡片都按四个问题组织：对象是什么、计算发生在哪里、产品处在哪个层级、最大产业风险是什么。公司新闻稿如果说 “shipping”“available”“production”“prototype”，只按其原始口径使用；除非来源明确说明 volume shipment 或客户量产导入，否则不推断为规模化商业成功。

## 一句话理解

公司卡片是 taxonomy、产品层级和商业现实的对齐表。

## 产业启示

对 CIM/PIM/NMC 公司，最重要的不是记住宣传数字，而是看它能否同时交付硬件、软件、供应链和客户验证。分类错误会直接导致商业判断错误：把 PIM 当 CIM 会高估 cell-level 创新，把 demo card 当量产产品会高估市场成熟度。
