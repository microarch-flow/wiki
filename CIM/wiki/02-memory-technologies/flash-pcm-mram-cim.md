# Flash / PCM / MRAM-CIM

## 路线定位

这类路线通常强调非易失、低功耗和端侧落地，适合模型较固定、功耗极严苛的设备。

## 重点问题

- 非易失优势是否真正转化为系统收益
- 读写特性是否适合目标应用
- 是否更适合 always-on AI 或 sensor-side AI
- 与 SRAM-CIM 相比，优势落在容量、待机功耗还是成本

## 关键指标

- retention
- read latency
- write cost
- standby power
- model deployment constraints
