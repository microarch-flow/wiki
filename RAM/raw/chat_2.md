# 1️⃣ SRAM 的直觉理解

* **SRAM = Static RAM（静态随机存取存储器）**
* 每个 bit 用 **6 个晶体管（6T cell）** 存储，不需要电容，也不需要刷新
* 断电就丢数据（非易失性只有 DRAM 也没有）
* 访问速度极快 → 几纳秒级延迟
* 功耗较高，面积大，成本高 → 不适合做大容量主存

💡 直觉比喻：

* **SRAM** = “寄存器式小仓库”，存取快，但占地大，放不下太多东西
* **DRAM** = “仓库式大仓库”，存放量大，但存取慢，需要搬运工具（行缓冲）

---

# 2️⃣ SRAM 单元原理（电路层）

## 2.1 6T SRAM 单元

| 元件                        | 作用        |
| ------------------------- | --------- |
| 4 个晶体管组成两个交叉反相器           | 存储稳定的 0/1 |
| 2 个访问晶体管（pass transistor） | 控制读写访问    |

### 特点

* 不需要周期刷新 → “static”
* 可随机、按 bit 直接访问
* 每个 bit 面积比 DRAM 大约 6~10 倍（depends on 工艺）
* 速度快 → 主要用于 CPU/SoC 内部缓存

---

## 2.2 速度与延迟

* SRAM 通常纳秒级延迟
* DRAM 通常几十纳秒（受 tRCD/tRP/tRAS 限制）
* 因此 SRAM 适合做**L1/L2/L3 Cache**，DRAM 做**主存**

---

# 3️⃣ SRAM 与 DRAM 的对比

| 特性    | SRAM         | DRAM                       |
| ----- | ------------ | -------------------------- |
| 存储单元  | 6T 晶体管       | 1T1C                       |
| 容量    | 小（几 KB~几 MB） | 大（GB~TB）                   |
| 访问速度  | 非常快（几 ns）    | 慢（几十 ns）                   |
| 是否刷新  | 不需要          | 需要周期刷新                     |
| 功耗    | 静态功耗高        | 静态功耗低，动态功耗可控               |
| 面积成本  | 高            | 低                          |
| 使用场景  | CPU/SoC 缓存   | 主存、GPU / AI accelerator 内存 |
| 接口复杂度 | 简单（直接寻址）     | 复杂（行/列、Bank、Prefetch）      |

---

# 4️⃣ 协议与访问机制

## 4.1 SRAM 访问

* 直接通过**地址线**访问
* 读取/写入一个或多个 bit（按阵列设计）
* 不受行缓冲 / page hit 的约束
* 控制器复杂度低 → 可以直接在 CPU 内部集成

## 4.2 DRAM 访问

* 需要**Activate → Read/Write → Precharge**
* Bank / Row / Column 层次结构
* 高并行度 / Prefetch / Pipeline 是必需
* 控制器复杂 → CPU 侧一般有 Memory Controller

---

# 5️⃣ 系统架构使用差异

| 内存类型 | 系统集成方式                             | 举例                                |
| ---- | ---------------------------------- | --------------------------------- |
| SRAM | 内嵌在 CPU / SoC die 内，靠寄存器阵列 / cache | L1/L2/L3 Cache，Register File      |
| DRAM | 外部芯片 / 封装，接口复杂                     | DDR4/DDR5 DIMM，LPDDR5/6，HBM stack |

---

# 6️⃣ 封装制造

* **SRAM**：

  * 直接做在 CPU / GPU / AI accelerator die 内
  * 一般和逻辑电路同工艺制造（FinFET / CMOS）
  * 因为小容量，封装成本不敏感

* **DRAM**：

  * 单独制造芯片，再封装（DIMM / PoP / MCP / HBM stack）
  * HBM、GDDR、LPDDR 有不同封装策略
  * 封装复杂度高，成本显著

---

# 7️⃣ 第一性原理对比总结

1. **存储机制差异**

   * SRAM：靠晶体管保持状态 → 不刷新 → 快
   * DRAM：靠电容存储 → 需要刷新 → 慢，但容量高

2. **面积与成本**

   * SRAM 单 bit 面积大 → 小容量 → 高成本
   * DRAM 单 bit 面积小 → 大容量 → 成本低

3. **访问模式**

   * SRAM：随机访问简单
   * DRAM：Bank / Row / Prefetch → 高并行度才能接近带宽极限

4. **系统设计影响**

   * SRAM → Cache、寄存器阵列 → 提供核心计算低延迟
   * DRAM → 主存 / 高带宽加速器内存 → 提供大容量、可扩展性
