# DDR5 / LPDDR5 / GDDR6 / HBM3 代际对照

上级：[03 DDR 协议与家族](./README.md)

相关：[DRAM 家族对照：DDR / LPDDR / GDDR / HBM](./ddr-lpddr-gddr-hbm-comparison.md)、[为什么不能只靠提频](./why-frequency-cannot-scale-forever.md)

## 为什么要做“代际”对照

只看 DDR、LPDDR、GDDR、HBM 四大家族还不够，因为工程上真正会遇到的是：

- DDR4 到 DDR5 升级了什么
- LPDDR4X 到 LPDDR5/5X 的重点是什么
- GDDR6 为什么仍然站得住
- HBM2E 到 HBM3/HBM3E 的核心变化是什么

更好的看法不是背参数，而是看每一代在补哪一类瓶颈。

## 一张总表

| 路线 | 主要升级方向 | 本质目标 |
| --- | --- | --- |
| DDR5 | 更高数据率、更强并行组织、平台带宽扩展 | 让通用主存继续跟上服务器带宽需求 |
| LPDDR5 | 更高能效、更高移动带宽、更强低功耗机制 | 在移动功耗预算内继续抬带宽 |
| GDDR6 | 更高板级显存带宽、更成熟 GPU 配套 | 在板级系统里维持高带宽平衡点 |
| HBM3 | 更高 stack 带宽、更高带宽密度、更强封装协同 | 服务 AI/HPC 的极致供数需求 |

## DDR5：通用主存继续扩带宽

DDR5 的升级重点可以概括为：

- 更高传输速率
- 更强调 bank/bank-group 层面的并行组织
- 让平台在不彻底改写部署方式的前提下继续抬总带宽

它不是试图把自己变成 HBM，而是让通用主存路线继续前进。

## LPDDR5：移动系统里的高能效升级

LPDDR5 的主线不是“追求最高绝对带宽”，而是：

- 在移动功耗预算下继续推速率
- 维持更好的每 bit 能耗
- 服务手机、轻薄本、边缘终端等紧凑系统

所以它的价值主要落在系统能效，而不是单纯跑分。

## GDDR6：显卡板级系统的现实最优点

GDDR6 的优势在于：

- 可在板级上围绕 GPU 组织较高带宽
- 封装和供应链成熟
- 相比 HBM，系统成本和集成门槛通常更可控

因此即使 HBM 更强，GDDR6 仍长期有存在价值。

## HBM3：高带宽路线的继续深化

HBM3 的方向更直接：

- 更高 stack 带宽
- 更高总带宽密度
- 更紧密依赖先进封装和供电/热设计协同

它体现的不是“内存单品升级”，而是 `memory + package + system` 一起升级。

## 该怎么比较这些代际

比较时不要只问“哪个 GB/s 更高”，而是先问：

- 它服务的是哪类系统
- 升级是在补带宽、能效还是封装边界
- 它的成本和部署代价是否被系统接受

## 一句话理解

`不同代际升级的重点并不相同：DDR5 继续守住通用主存，LPDDR5 守能效，GDDR6 守板级平衡点，HBM3 则把带宽问题继续推向封装级解法。`
