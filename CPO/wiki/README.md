## 维护原则

- 每页尽量只解决一个问题
- 优先区分系统层、封装层、器件层，再进入公司和产品
- 对论文、公司、路线尽量模板化记录，避免信息散乱
- 对时效性强的公司关系，优先以公开官方材料和具体日期为准
