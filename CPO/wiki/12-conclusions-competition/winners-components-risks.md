## 哪类公司更像平台赢家

更像平台赢家的公司，通常具备两类能力中的至少一类：

- 控制系统需求和客户入口
- 控制主平台 silicon 与 package 边界

按这个标准看，当前最像平台赢家的是：

- Broadcom
- NVIDIA
- Cisco
- AMD

其中强弱差异在于：谁已经把 photonics / CPO 公开发路线化，谁还处于能力补齐阶段。

## 哪类公司更像关键拼图

关键拼图公司未必控制最终平台，但它们可能决定路线是否能成立：

- Ayar Labs：optical I/O chiplet / remote light source
- Corning：fiber / connector / glass and interconnect-related capability
- Coherent / Lumentum：光器件与光源相关能力
- TSMC：先进封装与制造平台
- Alchip：ASIC + advanced packaging 协同

这类公司未必都成为“最大平台赢家”，但它们在关键阶段可能具备高议价能力。

## 最大风险点不是单点技术，而是跨层失配

最核心的风险通常来自：

- 平台方想推动，但客户不接受维护粒度变化
- optics 路线能跑通，但 manufacturing 爬坡不顺
- packaging 能做，但系统收益不够大
- 生态很热闹，但稳定供应关系并未形成

## 看一家公司时最重要的三个判断

1. 它是不是平台入口
2. 它是不是不可替代拼图
3. 它的风险来自技术、制造，还是 adoption

## 一句话总结

平台赢家决定 adoption 节奏，关键拼图决定路线能不能成立，而真正拖慢行业的通常是跨层失配，而不是单一部件弱一点。
