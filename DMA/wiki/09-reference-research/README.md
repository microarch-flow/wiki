# 09 参考资料与研究模板

这一部分用于统一术语、沉淀研究记录，并帮助你后续持续扩展这套 DMA wiki。前面 01-08 章已经把 DMA 的主线、案例和评估框架立住；这一章的任务是把这些判断方式固化成可复用模板，而不是让每次读新资料都重新发明一套语言。

## 推荐阅读顺序

1. [术语表](./glossary.md)
2. [研究模板](./study-template.md)
3. [阅读问题清单](./reading-questions.md)
4. [论文卡模板](./paper-card-template.md)
5. [IP 分析模板](./ip-analysis-template.md)
6. [案例索引](./case-index.md)

## 本章输出物

- 一套统一语言：descriptor、completion、consumer-ready、coherent、outstanding 等概念如何稳定使用
- 一组研究模板：读论文、看 IP、做案例记录时该保留哪些问题和字段
- 一个扩展入口：后续新增案例和资料时，如何接回这套 wiki 的主线
