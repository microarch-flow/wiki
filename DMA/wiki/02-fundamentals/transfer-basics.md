## 这页在回答什么问题

理解 DMA 时，最先要搞清楚它处理的基本对象是什么，以及“完成一次传输”到底意味着什么。

## DMA 处理的四类基本对象

- 源地址
- 目的地址
- 传输长度
- 传输属性

传输属性通常还会展开成：

- 方向
- 宽度
- burst 规则
- 对齐约束
- 中断/完成策略

## 比地址更重要的是语义

DMA 表面上在搬地址区间，本质上在执行一段带约束的数据移动语义。  
同样是 `A -> B`，其语义可能完全不同：

- 从外设 FIFO 读到内存
- 从 HBM 拉一块 tensor 到 local SRAM
- 从 CPU buffer 推到网卡发包队列

## 一次传输通常包含三个阶段

1. 描述与提交
2. 执行与搬运
3. 完成与通知

很多 bug 并不出现在“搬运阶段”，而出现在描述和完成语义没有对齐。

## 你必须区分的几个“完成”

- request 发出完成
- 数据真正到达完成
- 数据对消费者可见完成
- 中断或 doorbell 通知完成

这几个完成时刻不一定相同。

## 常见误区

- “传输长度就是总线拍数”
- “DMA 完成中断等于数据已经可安全消费”
- “memory-to-memory DMA 没有协议语义”

## 一句话理解

DMA 的最小理解单元不是“一个地址范围”，而是一条带有源、宿、长度、属性和完成语义的数据移动任务。
