## 这页在回答什么问题

当你已经读过主体章节后，如何快速查术语、指标、决策树、FAQ 和按目标的阅读路线。本章是整套 wiki 的速查层。

## 本章结构

| 文档 | 用途 |
| --- | --- |
| glossary | 查术语和缩写 |
| key-metrics-table | 横向比较路线、连接工艺和平台指标 |
| decision-tree-process-and-package | 从系统需求快速反推封装路线 |
| high-frequency-questions | 澄清最容易混的概念 |
| reading-roadmap-by-goal | 按学习目标给出最短阅读路径 |

## 使用方式

如果你遇到一个名词，先查 `glossary`。如果你要比较路线，查 `key-metrics-table`。如果你要从产品需求选工艺或封装，查 `decision-tree-process-and-package`。如果你觉得概念混在一起，查 `high-frequency-questions`。如果你要按目标学习，查 `reading-roadmap-by-goal`。

```text
term unclear -> glossary
route comparison -> key metrics
architecture decision -> decision tree
concept confusion -> FAQ
learning goal -> roadmap
```

## 与主体章节的关系

参考层不替代主体章节。它负责压缩、索引和回链；真正的解释仍在 `01` 到 `07`。当速查表给出结论时，应回到对应章节理解原因。

## 一句话理解

参考资料层是整套 wiki 的入口、索引和复习工具，用来快速定位概念、比较路线和回到正确章节。

## 架构师启示

架构师做路线判断时，不应只凭记忆使用术语。用参考层先统一词义、指标和决策树，再回到主体章节检查热、PI、SI、良率、测试和产业链约束。
