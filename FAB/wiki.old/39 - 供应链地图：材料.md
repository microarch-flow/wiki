## 为什么材料不能只当配角

先进封装里的材料不是“辅助品”，而是直接决定：

- 工艺窗口
- warpage
- 可靠性
- 高频损耗
- 接合与界面质量

## 1. 可以把关键材料分成 6 组

### 1. silicon / silicon platform 相关

- interposer wafer
- bridge silicon
- 3DIC silicon interface

### 2. RDL / dielectric / Cu 相关

- polymer dielectric
- Cu routing
- via 相关材料

### 3. bump / pillar / bonding 相关

- solder bump
- Cu pillar
- UBM / barrier / seed
- hybrid bonding 界面相关材料

### 4. underfill / mold / adhesive

- underfill
- mold compound
- temporary / permanent adhesive

### 5. decap / passive / power 相关

- MIM / embedded passive 相关材料
- power delivery 辅助材料

### 6. thermal 相关

- TIM
- lid / heat spreader interface 相关材料

## 2. 材料最核心的三类角色

### 电角色

- 高频损耗
- 介电特性
- 导电能力

### 力学角色

- CTE
- 模量
- 应力缓冲
- 翘曲控制

### 工艺角色

- 可图形化
- 可键合
- 可量产一致性

## 3. 为什么高端先进封装特别怕材料问题

因为越高端，工艺窗口越窄：

- RDL 更细
- bonding 更密
- die 更薄
- package 更大

于是材料的小偏差就更容易变成：

- 良率问题
- 界面问题
- 长期可靠性问题
