## 为什么设备链关键

很多先进封装工艺并不是“有没有原理”问题，而是：

`能不能用足够稳定、足够精确的设备，把工艺窗口持续打出来。`

## 1. 几类关键设备

### TSV / 硅加工相关

- 深孔形成相关设备
- 绝缘 / barrier / seed 相关
- Cu 填充相关
- backside thinning / grinding / CMP

### RDL 相关

- 介质形成
- 图形化
- 电镀
- 多层 build-up 制程设备

### 贴装 / 对位 / bonding

- die placement
- thermocompression bonding
- high-precision alignment
- hybrid bonding 相关设备

### 薄 die / carrier / debond

- temporary bonding
- debond
- 薄片 handling

### 测试与可靠性

- wafer sort
- package test
- 中间模块测试
- 温循 / 应力可靠性设备

## 2. 设备真正决定什么

- 对位精度
- 重复性
- 良率稳定性
- 工艺窗口宽窄
- 扩产能力

## 3. 为什么高端先进封装设备特别难补

因为先进封装设备不是只要“能做出来”就行，而是要：

- 在高精度下稳定运行
- 在大批量时保持一致性
- 和材料、工艺 recipe 紧耦合

所以设备短板往往不是单机短板，而是平台短板。
