# 先进封装测试：Wafer Sort、KGD、中测、Final Test

上级：[[10 - 共性工程问题]]

相关：[[09 - W2W 与 D2W]]、[[21 - HBM Stack 是怎么制造出来的]]、[[27 - CoWoS-S 的完整制造流程]]

## 为什么先进封装测试比传统封装更重要

因为先进封装里：

- 单颗 die 很贵
- HBM stack 很贵
- 组装步骤很多
- 失败后返工/修复更难

所以测试不能只放在最后，而是必须前移、分层、节点化。

## 1. Wafer Sort 是什么

Wafer sort 就是在晶圆阶段先做电测。

它的目标是：

- 尽早发现坏 die
- 做初步 binning
- 决定哪些 die 值得进入后续高成本封装流程

## 2. KGD 是什么

KGD = `Known Good Die`

直观理解：

就是已经通过足够测试、被认为适合进入后续高价值组装流程的裸 die。

在先进封装里，KGD 特别关键，因为如果坏 die 混进高成本堆叠或 CoWoS 组装，后面的损失会非常大。

## 3. 为什么 D2W 特别强调 KGD

因为 D2W 的一个核心优势就是：

- 先筛选 die
- 再把好 die 贴到底层 wafer 上

这样能明显降低有效良率损失。

所以：

- W2W 更依赖整片良率
- D2W 更依赖 KGD 管理

## 4. 什么是中测

中测不是一个固定唯一形式，而是指：

`在最终成品测试之前，对中间模块/中间阶段做测试`

比如：

- HBM stack 完成后的测试
- interposer module 形成后的测试
- 某些堆叠阶段后的电性检查

它的意义是把问题尽量拦在前面，而不是等 final package 才发现。

## 5. Final Test 是什么

Final test 就是最终封装完成后，对成品进行电性/功能/部分性能和筛选测试。

这是出货前的关键关口，但在先进封装里它已经不是唯一关键测试点。

## 6. 为什么测试节点要前移

因为先进封装产品的价值密度很高。

如果等最后才发现问题，可能已经浪费了：

- logic die
- HBM stack
- interposer
- substrate
- 多轮 assembly 成本

所以测试前移本质上是在保有效良率和保成本。

## 7. 先进封装测试比传统测试难在哪

### 7.1 对象更多

不再只是单 die，而是：

- 多 die
- HBM stack
- interposer module
- 3D stack

### 7.2 故障隔离更难

坏的是：

- logic die
- memory stack
- bump
- TSV
- interposer routing
- bonding interface

判断起来更复杂。

### 7.3 可接触性更差

堆叠以后，某些内部节点不再容易直接探测。

### 7.4 测试与设计必须一起考虑

先进封装测试不是纯后置动作，而要在架构和 DFT 阶段就考虑可测试性。

## 8. 一个更完整的测试链条理解

可以把先进封装测试链条粗略理解成：

1. wafer sort
2. die 筛选 / KGD
3. 某些中间模块测试
4. package 级测试
5. final test
6. reliability / stress test

每个节点都在做一件事：

`尽量在更早阶段把坏件挡住。`

## 9. 最终压缩理解

在传统低复杂度封装里，测试更像“最后验货”；  
在先进封装里，测试更像“穿插在整条制造链上的风险控制系统”。
