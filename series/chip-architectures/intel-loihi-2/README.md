# Intel Loihi 2 怎样用脉冲更新神经元状态？

Loihi 2 是 Intel 的神经形态研究芯片。核间以脉冲消息通信，消息可以携带整数负载。下游用负载乘以突触权重，再更新保存在本地的神经元状态。神经元微码决定何时发出下一条消息。本文用一种 Sigma-Delta 神经元说明状态如何随事件变化。 [Intel Loihi 2 技术简报](https://www.intel.com/content/dam/www/central-libraries/us/en/documents/neuromorphic-computing-loihi-2-brief.pdf)

## 一个脉冲怎样影响下一次发放

Loihi 2 的神经形态核在本地存储突触权重和神经元状态。芯片上的网络把脉冲送给目标神经元。对于本文采用的 Sigma-Delta 模型，脉冲里的整数表示上游激活的变化量 Δx。

1. **更新累加器。** 将输入变化量 Δx 乘以权重，再加到神经元已经保存的累加值中。
2. **求当前激活。** 对累加值加偏置，应用 ReLU，再按配置重新缩放，得到当前激活。
3. **检查发放条件。** 用当前激活减去上次发放时记录的激活。只有差值的绝对值大于阈值，才发出带符号的差值，并更新这份记录。

累加值保存已经接收的输入贡献。上次发放值记录下游通过脉冲可重建的激活。两项状态可以在同一步取不同的值。 [Intel 技术简报](https://www.intel.com/content/dam/www/central-libraries/us/en/documents/neuromorphic-computing-loihi-2-brief.pdf) · [Sigma-Delta 论文第 3.1 节与算法 1](https://arxiv.org/html/2505.06417v2)

## 教学算例｜何时发送负增量

假设只有一条输入连接。权重取 2，偏置取 0，缩放取 1，发放阈值取 2。初始输入、累加值和上次发放值均为 0。输入变化量按相邻输入精确求差，在本例中各次计算均无溢出。

| 输入值 | 当前激活 | 差值及处理 |
| ---: | ---: | --- |
| 3 | 6 | +6，发放 |
| 3 | 6 | 0，保持 |
| 5 | 10 | +4，发放 |
| 4 | 8 | −2，保持 |
| 3 | 6 | −4，发放 |

表中的「发放」表示发送本行差值。「保持」表示沿用上次发放值。第四步差了 −2，幅度等于阈值，因此下游仍保留 10。第五步仍以 10 为参考，发出 −4。下游从 0 开始，按收到的顺序累加负载，重建值是 6、6、10、10、6。这个表按算法步骤复算。 [算法 1 的发放条件](https://arxiv.org/html/2505.06417v2)

## 论文实机结果｜PilotNet 的 I/O 边界

PilotNet 用前视图像预测转向角。论文作者把模型转换成 Sigma-Delta 网络，用一颗 Loihi 2 执行。测试用 VPX 开发板装有 16 颗 Loihi 2。作者用 nxkernel 0.3.0 部署模型，基准配置为每份输入执行 16 个脉冲网络时间步，使消息通过各层。 [论文第 3.1、3.5 节与表 1](https://arxiv.org/html/2505.06417v2)

表 3 在发放阈值为 0 时给出 PilotNet 的时延。含板外 I/O 的配置报告 **2.50 ms**，预载数据进行片上回放的配置报告 **1.13 ms**。这两项是论文在指定模型和测试边界下的实机结果。应用的完整时延还取决于采集、编码、传输和输出处理如何接入。 [论文表 3 与测量方法](https://arxiv.org/html/2505.06417v2)
