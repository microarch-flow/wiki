# Eyeriss v2 怎样在压缩域累加？

Eyeriss v2 是面向移动设备的神经网络加速器研究设计。它让处理单元（PE）直接读取压缩的激活和权重，跳过零值，并找到每次乘积对应的部分和。本文按论文图 16–17 跟踪单个 PE 的取数和累加。 [IEEE JETCAS 论文，图 16–17](https://eems.mit.edu/wp-content/uploads/2019/04/2019_jetcas_eyerissv2.pdf#page=10)

## 图 16｜怎样找到一列的非零权重

论文使用压缩稀疏列（CSC）格式。每个权重列对应输入窗口中的一个位置，每一行对应一个输出通道。地址向量记录每列的起点，连续两个地址界定这列的数据范围。数据向量存放非零权重，计数向量记录每个权重前跳过了多少个零。每列单独计数。 [论文第 IV-A 节，图 16](https://eems.mit.edu/wp-content/uploads/2019/04/2019_jetcas_eyerissv2.pdf#page=10)

图 16 从 0 编号。第 1 列的起点是 2，下一列起点是 5，因此 PE 读取位置 2、3、4 的三项权重 *c*、*d*、*e*，以及各项的零计数。第 3 列的两个边界地址都是 6，读取区间为空。 [论文图 16](https://eems.mit.edu/wp-content/uploads/2019/04/2019_jetcas_eyerissv2.pdf#page=10)

## 图 17｜先取激活，再取权重

1. **读取非零激活。** PE 先读激活的地址暂存区，再从激活的数据暂存区取出零计数和值。PE 根据跳过的零恢复这个激活在输入窗口中的位置。
2. **读取对应的权重列。** PE 用该位置查权重的地址暂存区，再从权重的数据暂存区取出该列的零计数和值。若列的两个边界地址相同，就没有乘积要累加。
3. **更新部分和。** PE 根据权重的零计数恢复输出通道。将激活与权重相乘后，把乘积加到该通道的部分和。更新后的值写回部分和暂存区，或由 PE 输出。

这个顺序使 PE 只在遇到非零激活时查询对应的权重列。权重位置仍须解码，因为连续读出的两个非零权重可能对应不相邻的输出通道。 [论文第 IV-A 节，图 17](https://eems.mit.edu/wp-content/uploads/2019/04/2019_jetcas_eyerissv2.pdf#page=11)

## 教学算例｜只更新两个通道

取一个输出位置和 1 × 1 卷积核。假设两个输入通道的激活为 [0, 2]，四个输出通道的部分和初值均为 0，乘加无溢出。权重第 0 列为 [5, 6, 7, 8]，第 1 列为 [3, 0, 4, 0]。

激活流只提供值 2，前导零计数为 1，因此 PE 取权重第 1 列。两列的边界地址依次为 [0, 4, 6]，PE 只读第 1 列的区间 [4, 6)。从列首开始，用零计数跳过空位置。

| 跳过的零 | 非零权重 | 部分和更新 |
| ---: | ---: | --- |
| 0 | 3 | 通道 0 加 2 × 3 = 6 |
| 1 | 4 | 通道 2 加 2 × 4 = 8 |

结果为 **[6, 0, 8, 0]**。按稠密方式逐项计算有 8 次乘加，压缩域只需 2 次有效乘加。这两个计数只描述算术工作量。实际执行还要取地址、解码零计数并读写部分和。论文给 8 位激活和权重各配 4 位零计数，并在稀疏度低时支持读取未压缩数据。 [论文第 IV-A 节](https://eems.mit.edu/wp-content/uploads/2019/04/2019_jetcas_eyerissv2.pdf#page=10)
