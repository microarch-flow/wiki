# 量产与生命周期

<span class="micro-legacy-anchor" id="05_production_and_lifecycle量产与生命周期"></span>量产将通过工程验证的设计变成可持续供应、可追溯的产品。产品工程和质量团队需要把硅后测量、产线筛选、可靠性样本和供应条件连接起来。

## 主流程

工程试产可与特性化和资格鉴定重叠。放行评审检查工作范围、试产数据、生产测试、资格鉴定、质量问题和客户要求。放量后继续监控产线与供应链，异常批次回到处置和变更流程。全局依赖见[生命周期导读](../00_overview/01_full_lifecycle.md#阶段之间的回环)。
