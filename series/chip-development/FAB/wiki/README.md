# FAB 制造与封测

<span class="micro-legacy-anchor" id="芯片制造与封测"></span>这一组文章解释工艺、封装、晶圆筛测、成品终测与可靠性。它将架构选择连接到可制造、可测量的物理对象。项目的交付物与职责见[芯片开发生命周期](../../process/00_overview/01_full_lifecycle.md)。

## 阅读顺序

1. [从晶圆到成品的总览](01-overview/README.md)区分晶圆、裸片、封装件与鉴定样本。
2. [晶圆制造](02-front-end-fabrication/README.md)查看器件、金属、工艺规则与 PPA。
3. [晶圆筛测与 CP](03-wafer-test-and-cp/README.md)看如何在组装前分档和筛选。
4. [封装结构与工艺](04-back-end-packaging/README.md)区分 2.5D、3D、HBM 堆栈和使用的组件。
5. [成品终测与可靠性](05-final-test-and-reliability/README.md)理解终测，并区分筛选、鉴定和失效分析。
6. [封装工程约束](06-cross-cutting-engineering/README.md)查供电与信号、热机械和跨工序良率。
7. [供应商与产业分工](07-industry-map/README.md)查公开披露的对象及阶段。
8. [FAB 参考资料](08-reference/README.md)查术语、指标和选型路径。

跨系列阅读时，HBM 的存储协议和访问机制见[存储系统](../../../storage/03-dram/protocols/hbm-stacked-wide-io.md)。芯粒间协议和测试访问见[封装内芯粒互连](../../../interconnect/D2D/README.md)。电路到时序的基础见[电路与时序基础](../../../microarchitecture/02-pipeline/electrical-timing-foundations.md)。
