# TSV 到底是什么，和 2.5D、3D 是什么关系

上级：[[00 - 先进封装 Wiki 索引]]

相关：[[04 - Si Interposer]]、[[08 - 3D IC]]、[[21 - HBM Stack 是怎么制造出来的]]

## 先给结论

TSV = `Through-Silicon Via`，硅通孔。

它的本质是：

`在硅内部打出垂直导通路径，把信号、电源或地从硅的一面引到另一面。`

最重要的一点是：

`TSV 不是 3D 本身，也不是 2.5D 本身；它是一种垂直互连能力。`

所以：

- 有些 2.5D 平台会用 TSV
- 有些 3D stack 会用 TSV
- 但“用了 TSV”不等于“就是 3DIC”

## 1. 为什么要有 TSV

因为当系统不再只在平面上连线，而是开始利用硅作为互连平台或做多层堆叠时，就需要一种方式把电从硅的一面穿到另一面。

传统平面金属布线做不到这件事，所以要引入 TSV。

## 2. TSV 最直观的作用

### 2.1 在 interposer 里

如果 logic die / HBM 在 interposer 顶部，而 substrate 在下面，就需要把信号和电源从 interposer 顶面引到底面。

这时 TSV 的作用是：

- 上层 die 侧互连
- 下层 substrate 侧引出

### 2.2 在 memory stack 里

HBM 这类堆叠式 memory 需要多层 die 之间形成垂直通路，TSV 就是核心支撑之一。

### 2.3 在某些 3DIC 结构里

如果某层 die 需要把连接从正面带到背面，或者让背面进一步引出，TSV 也会参与。

## 3. TSV 的本质结构

可以把它理解成：

- 在硅里形成高深宽比孔洞
- 做绝缘层
- 做 barrier / seed
- 再用金属填充

所以 TSV 不是“挖个洞就通了”，而是一整套微纳加工与金属化工艺。

## 4. TSV 和 2.5D 的关系

### 4.1 为什么 Si interposer 常用 TSV

Si interposer 顶部负责高密度 routing，底部要接 substrate。  
如果没有 TSV，顶部和底部之间就很难建立高密度垂直引出。

所以很多 Si interposer 平台里，TSV 是关键能力。

### 4.2 但 2.5D 不等于一定有 TSV

比如某些 RDL interposer 路线，其核心平台并不是 TSV-based silicon interposer。

所以更准确的说法是：

`TSV 是很多 2.5D 平台的重要实现手段，但不是 2.5D 的定义本身。`

## 5. TSV 和 3D 的关系

### 5.1 为什么很多 3D stack 会用 TSV

因为堆叠以后，有些层需要把电从一面送到另一面，TSV 正好是垂直通路。

### 5.2 为什么“3D = TSV”不准确

因为 3DIC 的核心定义是垂直堆叠集成，而不是某一种具体通孔结构。  
有些更高密度 hybrid bonding 路线，重点在于 die-to-die 直接连接；TSV 是否存在、放在哪层、承担什么角色，是结构设计的一部分，不是定义本体。

## 6. 为什么 TSV 难

### 6.1 它是高深宽比结构

孔很深、很细，对加工一致性要求高。

### 6.2 它会带来额外应力

金属、绝缘层和硅之间会形成热机械耦合，对邻近器件和结构都有影响。

### 6.3 它会占硅面积

TSV 不是零成本功能，会带来面积损失与设计约束。

### 6.4 它会影响热和可靠性

它不仅是电连接结构，也会改变热路径和局部应力分布。

## 7. 一个最有用的心智模型

### TSV

是“硅里的垂直通道”

### 2.5D

是“高密度横向集成架构”

### 3D

是“垂直堆叠集成架构”

三者关系是：

`TSV 是能力，2.5D/3D 是系统结构。`
