# 大陆先进封装：材料、基板、设备分别卡在哪

上级：[[16 - 大陆先进封装供应链现状]]

相关：[[14 - 为什么台积电领先先进封装]]、[[15 - CTE、热应力与 Warpage：从概念到 3DIC]]

## 先给结论

如果只看封测厂，容易得出一种错觉：平台已经差不多了，剩下只是时间问题。

但真正拉开差距的，往往是三类更底层的东西：

- 材料
- 基板
- 设备/工艺装备

更准确地说，大陆先进封装的难点不是“某一项完全没有”，而是：

`很多环节已经有能力，但在最高性能要求、最高一致性要求、最高良率要求和大规模量产交付要求下，仍有明显短板。`

## 1. 材料卡在哪

### 1.1 RDL 介质和相关材料

高端 RDL / fan-out / interposer 体系要求：

- 更细 line/space
- 更低介电损耗
- 更好的机械顺从性
- 更稳定的热机械表现

所以不只是“有 PI/聚合物就够了”，而是要兼顾：

- 电性能
- 热稳定性
- 应力控制
- 与 Cu / via / underfill 的兼容性

大陆在这类材料上并非空白，但在最顶级性能和稳定量产一致性上，通常仍偏追赶。

### 1.2 underfill / mold compound / adhesive

这些材料经常被低估，但它们直接影响：

- die shift
- warpage
- delamination
- bump / RDL / interface stress

在高端 2.5D/3D 封装里，材料不是辅助项，而是良率核心项。

难点在于：

- 热机械参数要匹配
- 制程窗口要宽
- 长期可靠性要稳定

### 1.3 high-end decap / embedded passive 相关材料

先进封装越来越重视 PDN，相关材料和结构包括：

- MIM 相关材料
- trench / decap 集成所需材料体系
- 低损耗 power routing 相关材料

这类能力常常不是单一材料问题，而是材料 + 工艺 + 设计协同问题。

## 2. 基板卡在哪

### 2.1 不是“有 substrate 就行”，而是要有高端 ABF 体系

高端 AI/HPC 封装需要的不是普通基板，而是：

- 高层数
- 高 I/O
- 高电流供电
- 高速信号
- 更严苛平整度和 warpage 控制

这直接把难度拉到高端 ABF build-up substrate。

### 2.2 尺寸越大，问题不是线性增加

当 package 继续放大时，基板难点会同时变成：

- 尺寸稳定性
- 翘曲控制
- 供电网络
- 高频损耗
- 装配兼容性

因此，基板常常不是“配件”，而是决定高端封装上限的核心平台。

### 2.3 大陆的现实位置

更稳妥的判断是：

- 中高端基板能力在持续提升
- 面向高性能封装的 substrate 供应能力在扩展
- 但若对标台积电最强 CoWoS / AI package 对 substrate 的要求，仍有明显代差

这也是为什么很多高端先进封装问题，最后会回到基板上。

## 3. 设备卡在哪

### 3.1 细 pitch 对位与 bonding

先进封装往更细 pitch 走以后，设备难点包括：

- 高精度贴装
- 高精度对位
- thermocompression bonding
- hybrid bonding 相关设备链

这些设备不是“能工作”就够了，而是要在极窄窗口下维持稳定高良率。

### 3.2 薄 die handling

3DIC、HBM、超大封装都要求：

- 更薄 die
- 更复杂搬运
- 更复杂 temporary bonding / debonding

这类设备链如果不成熟，良率会直接受限。

### 3.3 TSV / backside / CMP / 表面处理

如果要往更高端 2.5D/3D 走，设备链还涉及：

- TSV 相关工艺设备
- backside thinning / grinding
- CMP
- 混合键合前的表面处理与洁净控制

这些都是先进封装真正往“硅级集成”走时必须补齐的装备链。

## 4. 真正难的是三者耦合

先进封装难点不是：

- 单独缺一种材料
- 单独缺一种设备
- 单独缺一块基板

而是三者一起耦合：

- 材料决定工艺窗口
- 设备决定能否稳定落工艺窗口
- 基板决定整包能否真正落地

所以即使某项单看“已经能做”，也可能因为另外两项不够强，最终卡在量产。

## 5. 一个更准确的判断框架

以后看大陆先进封装，不要只问“有没有这项技术”，而要问：

1. 材料参数是否足够支撑最高端场景
2. 基板是否足够支撑大尺寸、高 I/O、高速与高电流
3. 设备是否能在高一致性下量产
4. 三者组合后，良率、交期和成本能不能闭环

只有这四个问题都成立，才是真的产业化能力。

## 6. 最终压缩结论

大陆先进封装的主要短板，不只在封测厂平台本身，而在：

- 高端材料体系
- 高端 substrate / ABF 平台
- 高精度 bonding、薄 die handling、TSV / hybrid bonding 等设备链

如果这些底层能力不能一起跟上，那么即使平台路线存在，也很难稳定支撑最顶级 AI/HPC 级 2.5D/3D 量产。
