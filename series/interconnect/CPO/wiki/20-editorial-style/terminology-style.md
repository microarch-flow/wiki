# 术语与写法约定

上级：[20 编辑规范与页面模板](./README.md)

## 总原则

- 中文为主，英文术语在首次出现时补全
- 高频术语尽量保持固定写法，不在不同页面来回切换
- 时效性内容尽量写绝对日期，不写“近期”“目前”

## 推荐固定写法

| 推荐写法 | 说明 |
| --- | --- |
| CPO（Co-Packaged Optics） | 首次出现补全英文 |
| NPO（Near-Packaged Optics） | 与 CPO 同级写法 |
| pluggable optics | 需要强调模块时再写 `pluggable module` |
| silicon photonics | 非必要不缩写成 `SiPh` |
| optical I/O chiplet | `chiplet` 是关键含义，不建议省略 |
| external laser / remote light source | 同一页尽量选一种主写法 |
| PIC（Photonic Integrated Circuit） | 首次出现补全 |
| driver / TIA | 首次出现最好补中文说明 |
| connectorization | 优先保留英文写法 |
| qualification | 工程语境下优先写 `qualification` 或 `reliability qualification` |

## 日期写法约定

优先写：

- `截至 2026-05-05`
- `在 2025-03-18 官方材料中`
- `根据 2025-05-28 官方博客`

避免只写：

- 目前
- 当前
- 近期

## 公司关系写法约定

对公司生态关系，优先区分三层：

1. `公开生态协同`
2. `明确路线合作`
3. `稳定量产/供货关系`

如果公开材料没有明确到第 3 层，就不要擅自写成第 3 层。

## 一句话总结

这套 wiki 的写法目标，不是追求花哨，而是追求稳定、可比较、可维护。
