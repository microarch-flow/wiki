# 10 重点公司与合作关系图谱

这一章把前面的“产业链角色”和“供应链分层”进一步落到公司级。

目标不是列出所有公司，而是先回答：

- 哪几类公司最值得优先跟踪
- 这些公司在 CPO 生态里分别控制什么
- 目前公开可见的合作关系大致怎么连

说明：

- 本章优先使用公司官方新闻稿、产品页或官方材料整理
- 涉及时效性较强的合作关系时，以文中注明的公开时间为准
- 这里更适合做“研究入口”和“关系框架”，不适合当作法律或商业尽调结论
