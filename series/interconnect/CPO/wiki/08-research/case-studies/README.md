# 案例库

本目录先不追求覆盖大量具体论文，而是先建立三种最常见的读法：

- [案例：系统动机型论文怎么读](./system-motivation-paper.md)
- [案例：外置激光 CPO 论文怎么读](./external-laser-cpo-paper.md)
- [案例：热与可靠性论文怎么读](./thermal-reliability-paper.md)

## 为什么先这样组织

因为 CPO 论文很容易分散在系统、封装、硅光、器件、热设计等不同社区。先建立“读法模板”，比先堆一长串标题更适合系统学习。

## 这层和其他论文页怎么分工

- 这层只负责：教你“某类论文怎么读”
- [论文卡片库](../paper-cards/README.md) 负责：按主题沉淀具体论文
- [完整论文卡](../detailed-cards/README.md) 负责：把少数关键论文深入展开

如果你已经拿到一篇具体论文但不知道该怎么下手，先回到这里最合适。  
如果你已经清楚自己要读哪篇，就不需要在这层停留太久。
