# 论文卡片库

本目录用于沉淀“具体论文卡片”，和 [案例库](../case-studies/README.md) 的区别是：

- 案例库偏“怎么读”
- 论文卡片库偏“把具体论文放进统一框架”

## 推荐阅读顺序

- [系统架构类论文卡片](./system-architecture-papers.md)
- [硅光与光引擎类论文卡片](./silicon-photonics-engine-papers.md)
- [外置激光与光源架构类论文卡片](./external-laser-papers.md)
- [封装集成类论文卡片](./packaging-integration-papers.md)
- [热与可靠性类论文卡片](./thermal-reliability-papers.md)

## 使用方法

这里先给出适合 CPO 学习的首批卡片槽位。后续你看到具体论文时，直接往对应类别里补充，不要把系统、器件、封装、热论文混写在一页里。

## 这层和前后两层怎么分工

- 上一层：[案例库](../case-studies/README.md)
  作用：告诉你某类论文应该怎么读
- 这一层：论文卡片库
  作用：按主题分类沉淀具体论文
- 下一层：[完整论文卡](../detailed-cards/README.md)
  作用：把最关键的少数论文做成长卡深读

如果你是第一次开始读文献，先看阅读包和案例库。  
如果你已经在积累论文材料，这一层最适合做长期沉淀。

## 统一记录原则

- 一篇论文至少回答“它解决什么问题”
- 一篇论文至少给出“最关键的一个贡献”和“最关键的一个代价”
- 如果论文只在器件层成立，不要把它写成系统级结论
