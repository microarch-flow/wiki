# Cisco 深卡

上级：[11 重点公司深卡](./README.md)

相关：[Cisco：系统与硅光协同型 CPO 观察框架](../02-industry/company-cards/cisco-system-silicon-photonics.md)

## 它控制哪一段

Cisco 在 CPO 生态中的强项，是 `系统平台 + optics 内化能力 + 客户入口`。

它的关键不只是交换芯片，而是：

- network system integration
- enterprise / service provider customer access
- silicon + optics + system 共同设计

## 为什么现在值得跟踪

Cisco 的路线不是突然冒出来的。公开可见的关键节点包括：

- `2018-12-19` 宣布收购 Luxtera
- `2021-03-01` 完成 Acacia 收购
- `2026-02-10` 官方继续强化 Silicon One 与 coherent pluggables 的组合叙事

这说明 Cisco 一直在把光学能力往体内收，而不是只做外部采购者。

## 它的公开技术路线

Cisco 当前更适合理解成：

- 用 `Silicon One` 代表 network silicon 路线
- 用 Luxtera / Acacia 代表 optics 能力积累
- 根据场景在 pluggable、coherent optics、更深度集成之间权衡

它不一定是公开表述最激进的 CPO 公司，但它在“系统和运维视角”上的判断很值得重视。

## 它的公开合作与内化关系

Cisco 这里最关键的不是外部伙伴名单，而是两次关键收购：

- Luxtera：silicon photonics
- Acacia：coherent optics / high-performance optical interconnect

这让 Cisco 的 optics 能力更像内部平台能力，而不只是外部模块依赖。

## 它的商业模式和客户入口

Cisco 的客户入口很强：

- enterprise networking
- service provider
- cloud and web-scale networking

这意味着它比纯器件公司更有资格判断客户究竟愿不愿意接受更深度光电集成。

## 它的最大风险点

- 作为系统厂商，它会比纯技术推动者更谨慎
- 如果客户仍优先偏好成熟 pluggable 生态，它未必会最早大规模押注最激进 CPO
- optics 内化不自动等于 CPO 商业化路径马上清晰

## 你接下来最该看的观察指标

1. Cisco 是否公开把 Silicon One 与更深度 photonics 集成进一步绑定
2. 它是否开始更明确地区分哪些场景用 pluggable，哪些场景考虑更深集成
3. 是否出现更具体的封装级 photonics 路线公开材料

## 一句话总结

Cisco 在 CPO 里的看点，不是“喊得最响”，而是它能不能把 optics 内化能力真正转成系统级产品判断和客户 adoption。
