# 11 重点公司深卡

这一章把“公司观察框架”进一步展开成可持续使用的深卡。

每张卡尽量回答 7 个问题：

1. 这家公司在 CPO 生态里控制哪一段
2. 它为什么现在值得跟踪
3. 它的公开技术路线是什么
4. 它和哪些关键伙伴有公开关系
5. 它的商业模式和客户入口是什么
6. 它最大的风险点是什么
7. 接下来最该看的观察指标是什么

说明：

- 本章基于截至 `2026-05-04` 可见的公开官方材料整理
- 这里的“合作”优先指公开披露的路线协同或生态展示，不自动等于稳定量产供货

## 这层和前后两层怎么分工

- 上一层：[公司卡片](../02-industry/company-cards/README.md)
  作用：快速建立公司观察框架
- 这一层：公司深卡
  作用：展开公开路线、伙伴、商业模式、风险和跟踪指标
- 下一层：[研究结论与竞争观察框架](../12-conclusions-competition/README.md)
  作用：把公司信息压成平台判断、路线判断和竞争判断

如果你只想知道“这家公司大概在哪一层”，先看公司卡片。  
如果你只想要最终判断，直接去看第 12 章。  
如果你要做真正的公司研究，这一层最适合停留。
