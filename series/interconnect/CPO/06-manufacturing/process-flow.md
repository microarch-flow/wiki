# 制造流程

上级：[06 制造、测试与良率](./README.md)

相关：[产业链与角色](../02-industry/value-chain.md)、[测试、可靠性与失效定位](../05-electrical-thermal-reliability/reliability-test.md)

## 可以把制造流程粗略理解为多条链路汇合

一套 CPO 系统通常不是单一路径生产出来的，而是多条子链路最后汇合：

- 交换 ASIC 制造与封装准备
- driver / TIA / 控制芯片制造
- PIC 或 optical engine 制造
- 激光器或外置光源供应
- 光纤、连接器、耦合件准备
- 共封装装配、对位、固化、测试

例如，一条工艺路线先分别测试 ASIC 和光引擎，再将通过筛选的部件装入封装；完成光纤或波导对位后，进行封装级电光测试，最后做系统联调。另一些路线会调整光学连接和回流的先后顺序。顺序由器件耐温、可访问测试点、对位窗口和返修方法共同约束，不能从示例推断所有产品都采用同一流程。

## 制造中最敏感的步骤

### 精密对位与耦合

- 光学耦合对位置误差敏感
- 对位窗口直接影响插损、良率和节拍

主动对位根据实测光功率寻找工作点；被动对位依靠几何基准。两者都要用目标结构的损耗、容差、长期漂移和装配节拍评估，不能只根据是否使用主动对位判断成本。

### 混合集成

- 不同材料和器件热膨胀行为不同
- 机械应力会影响长期可靠性

### 热结构装配

- 散热器不能只服务 ASIC，还要兼顾光器件工作窗口
- 光纤引出与散热结构常常互相掣肘

## 为什么制造比传统模块更难

因为传统模块更像一个相对独立的光器件产品，而 CPO 更像“高热逻辑芯片 + 高速模拟电路 + 精密光器件 + 先进封装”的联合装配体。

## 关键指标

- 对位精度
- 耦合损耗
- 装配节拍
- 封装后测试通过率
- 返修能力
