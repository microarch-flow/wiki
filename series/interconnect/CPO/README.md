# 共封装光学（CPO）

<span id="cpo-wiki"></span>

共封装光学（CPO）将光引擎与主芯片在封装层级紧密集成，以缩短部分高速电通道。它同时改变光链路、散热、制造、测试和维护边界。收益要按具体系统比较。
