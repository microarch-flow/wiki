# 07 性能、诊断与查阅

上级：[系统网络](../README.md)

先从业务得到流量与完成目标，再建立预算、测量和诊断证据。模型、命令示例和硬件实测必须分开；最后的资料页提供复核入口。

## 阅读顺序

1. [业务与流量](workload-patterns.md)：RPC、存储和集群通信的不同需求。
2. [指标与性能预算](metrics-and-budget.md)：统一方向、单位、窗口和计时边界。
3. [TCP 与 RDMA 测试](benchmarking.md)：从最小路径测试扩展到应用。
4. [诊断与恢复](diagnosis-and-recovery.md)：用增量统计定位并处理失败状态。
5. [术语、版本与资料](glossary-and-sources.md)：核查来源、边界和未验证事项。

## 阅读提示

若测量与预算不符，先确认口径和实际路径，再回到对应协议章节。本文命令是测试起点，不是已经取得的硬件结果。
