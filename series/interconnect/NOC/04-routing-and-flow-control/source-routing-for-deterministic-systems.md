# Source Routing：源端怎样指定网络路径？

上级：[04 路由、仲裁与服务保证](../SUMMARY.md#04-routing-and-flow-control)；原章节：[04 路由、仲裁与服务保证](./README.md)

相关：[路由算法分类](./routing-algorithm-classes.md)、[地址映射与路由表](../05-system-integration/address-map-and-routing-table.md)、[编译器与 NoC 协同](../06-ai-noc-specifics/compiler-noc-co-design.md)

<span id="source-routing-for-deterministic-systems"></span><span id="这页在回答什么问题"></span>源路由让源端或软件选定完整路径，再由网络按约定执行。它可以支持静态计划，也可以在注入前依据运行时状态选择；路径由谁选择，与是否使用固定规则是不同问题。

## 路径如何表达

<span id="定义"></span>不同实现可以传递逐跳方向序列、方向与长度组成的 segment，或携带一个预先关联完整路径的 route ID。中间路由器读取当前位置对应的指示并选择输出。若一个包只携带目的地址，各路由器独立查表决定下一跳，则不能仅因使用了路由表就称为源路由。

<span id="路径行为更可控"></span>例如在无故障二维 Mesh 中，从 (0,0) 到 (2,1) 可以写成 E→E→N。源端或装载过程要检查每个方向存在、路径终点正确、长度和编码合法，并满足适用的资源依赖规则。

## 一次可核对的字段计算

假设每个方向和 Local 终止标记都用 3 bit 编码，header 依次携带所有方向及一个 Local 字段。4×4 Mesh 中从 (0,0) 到 (3,3) 的一条最短路径有 6 条路由器间边：E→E→E→N→N→N。加上 Local 共 7 个字段，路由字段是 7×3=21 bit。

这只计算所述路由字段，不包含目的地址、长度、对齐、保护位或其他包头内容。若接收端根据目的地址或单独的路径长度结束，就不必使用该 Local 字段。若允许更长的非最短路径，也不能把 6 hop 当作最大长度。

## 规划能力与共享资源

<span id="为什么-deterministic-npu-喜欢它"></span><span id="它带来的直接收益"></span><span id="更容易和静态调度协同"></span>路径可以与端点放置、通信需求和注入计划一起考虑，便于事先统计哪些流共享链路。[编译器与 NoC 协同](../06-ai-noc-specifics/compiler-noc-co-design.md)进一步讨论计划输入、输出和实际执行偏差。

<span id="router-局部逻辑可以更轻"></span><span id="它没有消失的复杂度"></span>源端携带的选择可能减少某些逐跳路径决策，也会引入编码、表、验证或更新工作。具体面积、时钟和能耗要看实现，不能仅凭路由类别确定。

<span id="共享-packet-switched-模型中的-vc-和仲裁"></span>在共享的 packet-switched 网络中，两条预选路径仍可能请求同一输出；还要按选定实现处理缓冲、信用和仲裁。若采用经过验证的无冲突静态 TDM 或电路式计划，可能不需要动态交换仲裁，但时隙、容量、时钟及端点条件仍需满足。

<span id="它也不天然无死锁"></span>路径提前选定不意味着路径集合无死锁。例如，单独正确的 XY 和 YX 路径混用时可能构造出资源等待环，见[四包例子](./deadlock-livelock-starvation.md#混用路径为什么可能形成循环等待)。检查应覆盖可用路径、VC 分配、消息依赖和端点，而不是只检查每条路径是否到达目的地。

## 路由更新和故障

<span id="它最适合哪类流量"></span><span id="一个现实判断"></span>更新 route ID 对应的路径时，一种做法是停止相关注入并等待旧包离网；另一种是让包携带版本，并保留对应表项直到旧包完成。这些是候选契约，需明确原子切换和版本生命周期。

如果链路已经失效，受影响的在途包未必能自行离网。此时需要系统定义报错、取消、重试或恢复条件；不能假设 drain 一定成功。路由确定性、事务顺序以及目的端重排也要分别检查。

<span id="和-bus-的差异"></span><span id="建模启示"></span>根据研究目标记录路径字段或 route ID、每跳执行、表版本、共享资源及完成事件；如果关心包头开销，再加入编码位数和封包对齐。

<span id="一句话理解"></span>源路由把路径选择前移，但执行、共享和更新仍需要明确契约。
