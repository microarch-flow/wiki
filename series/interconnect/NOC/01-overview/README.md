- NoC 要管理哪些路径、竞争与端点服务？

- 怎样分别描述工作负载、接口、拓扑、路由和服务？
- 按学习、系统分析或建模目标，后续应读什么？

## 一句话总纲

NoC 把片上通信的连接、转发和共享资源组织为网络；是否适合具体系统，要根据流量、端点服务、物理约束和实现成本判断。
