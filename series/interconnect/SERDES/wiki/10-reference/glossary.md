# 第一阶段术语表

上级：[SerDes 术语、资料与自测](./README.md)

术语的具体定义可能随标准或器件变化。查规格时应同时确认协议、方向、参考面和单位。

| 术语 | 本阶段使用的含义 |
| --- | --- |
| SerDes | 串行器与解串器；有时也指包含时钟和模拟前端的收发器。 |
| PHY | 物理层及其实现；覆盖范围因协议和实现而异。 |
| PCS / PMA | 特定协议中对物理层功能的划分；职责须查目标规范。 |
| TX / RX | 发送端 / 接收端。两者各有数据路径和控制状态。 |
| lane | 本专题例子中的单向串行数据通路；实际协议用法可能不同。 |
| bit / symbol | 比特是数字信息单位；符号是一个符号间隔内发送的信号状态。 |
| bit rate / baud | 每秒发送的比特数 / 每秒发送的符号数。 |
| UI | 本专题按一个符号的名义时间间隔使用。 |
| 差模 / 共模 | 差模为 `VP − VN`，共模为 `(VP + VN) / 2`；均基于同一参考。 |
| skew / jitter | skew 是指定对象之间的时序差；jitter 是事件相对指定理想时刻的偏差。 |
| 特性阻抗 | 传输线传播波的电压与电流关系，不是任意直流电阻。 |
| 反射 | 波遇到阻抗变化时，部分能量以返回波形式传播的现象。 |
| 插入损耗 / Sdd21 | 指定参考条件下的传输衰减 / 差分端口间前向传输参数。 |
| ISI | 其他符号的响应影响当前符号判决。 |
| 眼图 | 多个符号间隔的波形按时钟参考叠加的观察方式。 |
| PLL | 利用反馈建立输出与参考信号的频率 / 相位关系的环路。 |
| FFE | 前馈均衡；以多个带权抽头调整信号的实现方式之一。 |
| CTLE | 连续时间线性均衡器；调整不同频率分量的相对增益。 |
| DFE | 根据历史判决估计并抵消部分历史符号影响的均衡方式。 |
| CDR | 时钟与数据恢复；根据数据相关时序调整接收采样时刻。 |
| BER | 比特错误数与观察比特数之比；报告时需要注明测量范围和条件。 |
| 字边界 / lane 对齐 | 前者确定单条流从哪里分组，后者处理多条 lane 的相对位置。 |
