# 05 信号与指标：怎样读懂链路数据？

同一个“速率”可能表示符号、线路比特或有效数据。眼图、误码率和功耗也有各自的测量边界。本章先区分这些量，再学习如何比较数据。

## 阅读顺序

1. [NRZ 与 PAM4](./nrz-and-pam4.md)
2. [线路编码与加扰](./coding-and-scrambling.md)
3. [眼图与抖动](./eye-and-jitter.md)
4. [BER、置信度与 FEC](./ber-confidence-and-fec.md)
5. [带宽与每比特能耗](./bandwidth-power-efficiency.md)

读完后，应能给数字注明单位、参考位置和前提。涉及设备测试时，还需查阅对应标准、仪器设置和器件手册。
