# 查阅与验证：把理解变成可检查的结论

<!-- nav-title: 06 查阅与验证 -->

本章是查阅入口，不重复前面各章的机制解释。先固定术语和版本，再定义模型能检查的性质，最后根据故障现象选择证据和阅读入口。

文章中的教学模型、规范要求、实现选择和实际测量属于不同证据。阅读时应能回答：这个结论来自哪一类证据？依赖哪些条件？改变版本或拓扑以后是否仍成立？

模型验证页提供一个小型事件排列练习和定向竞争清单。它没有声称完成完整协议证明，也没有把软件仿真代替真实硬件合规验证。
