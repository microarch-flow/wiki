# 基础概念：先确定一致性保证的对象

<!-- nav-title: 01 基础概念 -->

多副本系统首先需要明确保证对象：是同一位置的数据，还是不同地址的访问顺序；是 CPU 缓存域，还是包含设备的访问路径。概念边界不清，后面的消息图即使画对，也可能被用于错误的问题。

本章从一条缓存行开始，建立权限与数据值约束，再用两个地址的例子区分内存顺序，最后检查设备进入一致性域的条件。

读完后，应能说明为什么主存可以暂时保存旧值、为什么硬件一致仍需要软件同步，以及为什么设备无缓存也可能发起一致性 I/O 访问。
