# 性能与可靠性：从访问过程到系统代价

<!-- nav-title: 05 性能与可靠性 -->

协议正确以后，还要判断系统是否高效，以及资源变化时是否继续可用。共享会产生权限迁移，远端容量会改变延迟和并发要求，错误和移除则改变访问能够成立的前提。

本章把应用有用工作、协议流量、链路承载和内存服务分开统计。所有数值算例均给出假设，不以线速率或单一缓存事件替代应用性能。

故障部分区分链路恢复、数据损坏、持久化和容量退出。读完后，应能为一项性能结论或资源移除操作列出必要的证据，而不是只给出“更快”或“支持热插拔”的标签。
