# 芯片与系统互连

本系列从事务语义、网络组织和物理链路出发，理解片上、封装内、设备和系统之间的通信。九个专题可组合使用。

1. [片上事务与总线（BUS）](BUS/wiki/README.md)：事务、握手、仲裁与桥接。
2. [片上网络（NoC）](NOC/wiki/README.md)：路由、缓冲、流控与拓扑。
3. [封装内芯粒互连](D2D/wiki/README.md)：跨 die 的接口、链路和协议承载。
4. [系统 I/O 互连（PCIe）](PCIE/wiki/README.md)：设备枚举、地址与事务。
5. [一致性与内存互连](COHERENCE/wiki/README.md)：缓存副本、一致性协议与设备内存访问。
6. [加速器互连](SCALEUP/wiki/README.md)：加速器间的访问与交换结构。
7. [系统网络](NETWORK/wiki/README.md)：以太网、RDMA、RoCE 和 InfiniBand。
8. [高速电链路（SerDes）](SERDES/wiki/README.md)：发送、接收、训练与验证。
9. [共封装光学（CPO）](CPO/wiki/README.md)：光引擎、封装和系统集成。

源码目录与网站发布路径分别配置。现有文章保留历史公开路径。
