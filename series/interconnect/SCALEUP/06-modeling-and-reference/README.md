# 06 建模、诊断与查阅

<!-- nav-title: 06 建模、诊断与查阅 -->

模型用于排除不可能的性能目标，测量用于检验真实系统，诊断用于解释二者的差距。三者需要共享同一套对象、单位与观察边界。

本章给出完整的四端点预算例子，整理异常定位流程，并提供术语、版本和一手资料入口。没有硬件证据的恢复能力和内部机制保持为待验证项。
