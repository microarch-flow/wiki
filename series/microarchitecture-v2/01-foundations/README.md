# 共同计算基础

运算电路不仅要算出一个数，还要知道从哪里取数、把结果放在哪里、何时可以开始下一项工作。这条路线从逻辑门和寄存器出发，建立 CPU、GPU、NPU 等计算架构共用的数字运算与执行机制。

## 从一次运算走到连续执行

假设要连续计算几组整数的点积。先找出怎样保存输入、选择操作数，再看加法器、乘法器和累加器怎样得到结果。换一种数值格式，还要重新考虑位宽、精度和舍入。到这一步，可以把这些电路和控制逻辑组织成一条数据通路。

接下来不再只看一次运算。第一组数据还在运算，第二组能否进入？如果输出位置被占用，哪些状态需要保持？如果几项工作都已准备好，谁先使用运算单元？这些问题把流水线、握手和调度连接起来，也是理解不同计算架构的基础。
