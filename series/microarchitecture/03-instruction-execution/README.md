本专题解释指令如何进入执行资源，以及结果如何成为程序的正式状态。先区分执行、写回与提交，再分析数据何时就绪、端口由谁获得。

## 阅读顺序

1. [从取指到提交](./instruction-lifecycle.md)：指令职责、精确异常与软件可见状态。
2. [数据依赖、旁路与发射](./dependencies-bypass-issue.md)：依赖链、操作数路径和资源选择。

这两篇建立执行主线。分支预测器、重命名、ROB 和 load/store queue 的完整实现还需继续专题展开。并行线程与通道组织见[并行执行](../04-parallel-execution/README.md)。
