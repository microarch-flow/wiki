# 05 · FPGA vs ASIC：可配置性的实现代价

同一逻辑可映射到 FPGA 或 ASIC。FPGA 的 LUT 与可配置互连支持更新；ASIC 可针对固定功能优化。面积、时延、功耗和项目成本的差距取决于器件、工具、硬块映射和工作负载。

[FPGA vs ASIC：LUT、mux 与实现开销](./lut-mux-and-10x-overhead.md)解释 LUT4 真值表、可配置布线，并介绍限定于 90 nm benchmark 的历史对照研究。它不给出适用于所有设计的统一倍数。
