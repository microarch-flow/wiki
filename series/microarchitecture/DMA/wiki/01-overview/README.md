# 01 概览与问题定义

这一部分先把 DMA 从“一个会搬数据的模块”提升为“系统里的数据移动执行层”来理解。后面所有章节都会默认你已经接受三个前提：DMA 有独立于 CPU 的执行节奏，DMA 的行为会被总线、内存和软件契约共同塑形，DMA 的性能问题很少只发生在 DMA 本体内部。

## 推荐阅读顺序

1. [DMA 在解决什么问题](./problem-statement.md)
2. [DMA 分类框架](./taxonomy.md)
3. [学习路线图](./learning-roadmap.md)
4. [按目标学习 DMA](./goal-oriented-navigation.md)

## 本章输出物

- 一套贯穿全库的主问题：DMA 为什么存在，它到底替 CPU 接管了什么
- 一张分类地图：不同 DMA 为什么长得不一样
- 一条阅读路径：后续该先学对象、微架构、软件契约还是系统瓶颈

## 建模提示

这一章不引入具体 IP 细节，但会确定后面建模必须分开的几个基本层次：`逻辑传输任务`、`DMA 执行节奏`、`系统资源耦合`、`软件可见完成`。如果这四层在思维里没有拆开，后面几章即使逐页读完，也很容易把问题重新混成“DMA 慢了”这种无效结论。
