# 08 DMA IP 与产业视角

这一部分不追公司新闻，也不追产品清单罗列，而是帮助你建立 DMA IP 评估和选型能力。前面几章已经把 DMA 的语义、微架构、系统耦合和案例画像拆开；这一章回答的是：当你面对一份 DMA IP 手册、第三方控制器或自研方案评审时，到底该看什么。

## 推荐阅读顺序

1. [DMA IP 与厂商图谱](./vendor-landscape.md)
2. [DMA IP 评估清单](./dma-ip-checklist.md)
3. [DMA 对照矩阵](./dma-comparison-matrix.md)

## 本章输出物

- 一条研究主线：DMA IP 的价值来自系统匹配度，而不是名字或峰值指标
- 一套评估口径：功能、微架构、系统接入、可观测性如何一起看
- 一张比较框架：不同 DMA 类型该如何放在同一张表里对照，而不丢掉系统语义
