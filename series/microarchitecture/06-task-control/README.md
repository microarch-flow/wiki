# 任务控制、同步与资源管理

一块数据在算，另一块正在搬入。即使两块数据各有缓冲，搬运和计算也可能争用同一个端口。把搬入、计算、写回画在同一条时间轴上，就能查清这次等待从哪里来。

## 阅读顺序

1. [第一块还在算，第二块能开始搬吗](./dma-compute-writeback.md)　跟踪两个分块各自占用的引擎、缓冲和端口，一直看到最后一次写回。

弄清连续计算两块数据的条件后，可以读《[同一块矩阵，CPU、GPU 和 NPU 怎样算？](../07-chip-organization/cpu-vs-gpu-core-area.md)》。要深入搬运本身，见 [DMA 与异步数据搬运](../05-dma/README.md)。
