# 没有 CPU 指挥，数字电路怎样按照规定的顺序工作？

**状态：待完善（文章提纲，尚非完整正文）。**

本文承接[组合逻辑电路](../combinational-logic/README.md)与[寄存器与时序逻辑](../registers-and-sequential-logic/README.md)。核心问题是：电路怎样利用已有状态和输入，决定下一拍的状态以及需要发出的控制信号？

## 当前状态怎样决定下一拍的状态？ {#next-state}

- 从寄存器加组合逻辑的反馈路径出发，区分当前状态、输入、下一状态。
- 用一位取反反馈回顾[触发器的二分频](../latch-and-divider/README.md#divider)，引出逐拍更新，而不重复其物理实现。

## 怎样让电路自动计数？ {#counter}

- 从两位状态的循环变化构造计数器，追踪每个有效时钟沿前后的状态。
- 说明计数使能、复位和终止计数的行为；这里只讲通用更新机制，不深入加法器微架构。

## 怎样用状态表示工作阶段？ {#fsm}

- 用等待、运行、完成等简单阶段引出有限状态机（FSM）。
- 从状态表示与转移条件推导状态寄存器、下一状态逻辑和输出逻辑。
- 用状态转移图、状态表和逐拍波形解释状态更新，按需要补充 Moore 与 Mealy 输出的区别。

## 状态怎样控制数据的保存和传递？ {#datapath-control}

- 用一个小型选择、保存和更新数据的电路，展示数据通路与控制通路怎样协同。
- 说明状态机产生选择、使能等控制信号，并由输入条件决定后续状态。
- 将复杂运算单元的组织、资源调度、流水线和执行语义留给计算微架构。
