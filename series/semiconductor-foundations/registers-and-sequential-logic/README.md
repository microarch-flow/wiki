# 多个触发器怎样保存和传递数据？

**状态：待完善（文章提纲，尚非完整正文）。**

本文承接[锁存器与触发器](../latch-and-divider/README.md)以及[组合逻辑电路](../combinational-logic/README.md)。已经理解单个比特怎样被保存和采样，本篇将追踪多个比特如何一起写入、保持以及逐拍传递。

## 怎样保存一组比特？ {#register}

- 简明回顾 D 触发器的边沿采样行为，不重复晶体管级实现。
- 从四个触发器共用时钟构造四位寄存器，说明输入 D 与当前输出 Q 的关系。

## 不想每拍都写入时，怎样保留旧值？ {#enable}

- 根据写入需求，引入 MUX 选择新输入或旧值反馈。
- 通过逐拍表格说明使能有效和无效时的行为，不把保持等同于停止时钟。

## 电路怎样得到指定的初始状态？ {#reset}

- 从上电初态的不确定性引出复位。
- 对比同步复位与异步复位的功能和行为，交代复位与写入使能的关系。

## 数据怎样在两个寄存器之间逐拍传递？ {#transfer}

- 在共用时钟、满足采样时序的前提下，跟踪两个寄存器沿前和沿后的值。
- 区分一拍内的组合传播与边沿更新，物理时序约束链接至[建立与保持](../pvt-and-path-delay/README.md)。

## 怎样让数据逐位移动？ {#shift-register}

- 通过相邻触发器的连接推导移位寄存器，以逐拍状态图展示串行和并行数据的变化。
