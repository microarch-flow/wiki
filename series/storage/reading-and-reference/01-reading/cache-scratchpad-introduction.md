# 06 · 存储 discipline：cache 与 scratchpad

[Cache 与 scratchpad](../../01-memory-hierarchy/02-access-paths/cache-vs-scratchpad.md)比较硬件自动管理和软件显式放置。地址已知不保证服务延迟固定；bank、端口、DMA 和仲裁仍可能形成冲突。给定完整初态和规则，cache 也可确定性模拟。
