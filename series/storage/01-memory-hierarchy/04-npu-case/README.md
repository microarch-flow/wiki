## AI 芯片内存架构：数据供应如何约束计算阵列 {#数据供应如何约束计算阵列}

一个常见的数据路径可以包含外存、搬运引擎、片上 SRAM、互连和计算单元。权重与激活可能从不同来源进入阵列；部分和可以留在处理单元（PE）内，也可以写入其他局部存储。结果可能送到下一计算阶段，也可能回写外存。

这些资源不一定排成单一路径。数据角色也不等于物理存储数量：多个角色可以共享 SRAM，某个角色也可能分布在多个位置。分析时，先画出目标实现的连接，再标出每块数据的生产者、消费者和驻留位置。

如果数据未能按计算所需的时间到达，阵列可能等待。反过来，数据供给充足时，计算能力、依赖、同步或输出路径仍可能限制任务。判断瓶颈需要结合实际工作量、资源占用和执行时间。

## 一句话理解

NPU 的数据路径由数据放置、搬运、计算和结果去向共同组成；容量、带宽与执行顺序需要一起检查。

## 建模启示

先确定模型要回答的问题。若要比较数据放置和供数，至少需要知道各数据块在哪里、经由哪些资源搬运、何时可被消费，以及资源是否被共享。若只研究粗略上界，可以使用更简单的模型，但不能据此解释具体 bank 冲突或等待原因。
