# SRAM 工艺缩放：密度、Vmin 与良率

上级：[SRAM 基础](./README.md)

相关：<span id="为什么-sram-在先进制程下不再线性-scale"></span><span id="这页在回答什么问题"></span>[6T SRAM cell](./6t-cell-bistable-storage.md) · [SRAM 阵列组织](./sram-array-organization.md) · [SRAM 漏电与低功耗](./sram-power-leakage-retention.md)

<p class="ram-problem-lede">工艺变化可能改善 SRAM 的密度、速度或能效，但这些指标不一定按同一比例变化。比较时还要看 cell 类型、外围电路、工作电压和目标良率。</p>

这里的“不再线性 scale”表示不能用一个统一的缩放系数推断全部结果，不表示 SRAM 停止进步，也不表示每一代工艺都会让每个指标变差。

## 为什么 SRAM 在先进制程下不再线性 scale？ {#bitcell-缩放vmin-与变异}

一个 6T cell 的面积受器件尺寸和版图规则约束，包括接触、布线及相邻器件的安排。完整 SRAM 宏还包含译码、感测、写驱动、电源和其他外围电路。即使 cell 面积缩小，宏面积也不会必然按完全相同比例缩小。

用一个归一化算例说明外围占比：假设同容量宏原来的总面积为 100，其中 cell 占 70、其他部分占 30。若 cell 数不变、每个 cell 面积减少 20%，而其他面积不变，新总面积为 `70 × 0.8 + 30 = 86`，仅减少 14%。这些比例都是教学假设，不是工艺或产品数据。

同一工艺中还可能有不同的 cell 选择。[Intel 的 32 nm 工艺介绍](https://www.intel.com/content/dam/doc/technology-brief/32nm-soc-platform-technology-presentation.pdf)展示了面向高速、低电压和高密度的不同 SRAM cell。这个例子说明选型目标会影响 cell 设计；不能用该资料中的面积直接推断其他节点或完整宏的结果。

## 降低电压时，哪些条件需要分别满足？

以常见 6T cell 为例：

| 要完成的任务 | 需要检查的条件 |
| --- | --- |
| 保持原值 | 供电、噪声和器件条件下，双稳态能否维持。 |
| 读取 | 感测是否正确，同时读扰动是否会改变 cell。 |
| 写入 | 写驱动能否在规定时间内改变状态并保持新值。 |
| 提供宏接口 | 阵列和外围路径能否在目标时钟及负载下满足时序。 |

降低电压可能改变器件电流、噪声裕量和读写时间，但变化方向与幅度取决于电路及条件，不能仅凭节点名称断言某个裕量一定单调恶化。[一项 6T SRAM 读稳定性与写入能力研究](https://ieeexplore.ieee.org/document/1717680/)讨论了这些指标和器件变异之间的关系。

`Vmin` 常指在指定任务、工艺角、温度、时序和失效或良率目标下满足要求的最低工作电压。保持模式的最低电压与正常读写的最低电压应分别确认。不同资料对边界和目标可能有不同定义；单独一个 `Vmin` 数字不能覆盖所有模式。

## 为什么大阵列需要关注失效分布？

即使多数 cell 工作正常，少数 cell 或外围路径的变异也可能影响整个宏。需要关注的是目标条件下的失效分布，以及测试、冗余修复和系统允许的错误范围；不能只看平均 cell。

下面只做概率示意。假设有 `N = 1,000,000` 个 cell，每个 cell 的失效概率都是 `p = 10⁻⁸`，它们相互独立；没有修复，且任何一个失效都使该宏不满足要求：

<div class="ram-calculation">
  <span>全部 cell 正常的概率 = (1 − p)<sup>N</sup> ≈ <strong>99.0%</strong></span>
</div>

这不是实际工艺的良率预测。真实失效可能相关，cell 的失效概率不一定相同；外围故障、冗余修复和不同的验收规则也会改变结果。[IBM 的 SRAM 稳定性研究](https://research.ibm.com/publications/sram-cell-design-for-stability-methodology)讨论了器件变异、阵列规模和可用冗余如何影响稳定性目标。

## 面积、速度和能耗为什么要一起看？

改变 cell、阵列切分或外围电路，可能改善某个工作条件下的稳定性或时序，也可能增加面积、控制复杂度或能量。例如，读写辅助电路可以扩大某些设计的工作范围，但其效果和代价需要针对具体实现评估。

工艺变化还会改变互连、供电和外围电路的约束。较快的晶体管不自动证明完整宏的访问路径更快；更小的 cell 也不自动证明在相同工作负载下总能耗更低。比较前应对齐容量、接口、端口、时钟、PVT 和失效目标。

## 一句话理解

工艺节点是重要条件，但不能代替 SRAM 宏的完整规格。密度、读写时序、保持条件、能耗和良率需要在同一工作边界下分别评估。

## 建模启示

架构模型不必为了每次访问都模拟器件失配，但应记录参数来源与适用范围。例如：目标工艺和宏配置、容量与端口、各工作模式的电压范围、时序与能耗表征条件，以及该数据对应的良率或失效目标。

如果目标宏没有某个配置的表征数据，模型可以做带标签的假设或插值，但不能把估算值写成已验证的硬件规格。简单地增加 bank 数也不能自动消除 cell 失效：在上面的独立失效示意中，若总 cell 数和各自失效概率不变，只改变分组，不会改变全部 cell 正常的概率。
