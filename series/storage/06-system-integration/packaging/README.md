## 这页在回答什么问题

同一种存储技术可以怎样进入系统？模块、芯片封装、die 堆叠和封装内互连处于不同层次。它们共同影响可连接的器件数量、布线、散热、测试、容量配置和维护方式。

## 封装如何改变存储接口边界

| 层次 | 要观察的对象 | 示例 |
| --- | --- | --- |
| 板级与模块 | 主板走线、连接器、模块及可更换边界 | DIMM/SODIMM 模块承载多个封装好的器件。 |
| 芯片封装 | 一个封装中有哪些 die，封装之间如何连接 | MCP 在一个封装中集成多个芯片；PoP 将封装叠放。 |
| die 与封装内互连 | die 如何堆叠、计算 die 怎样连接内存 | HBM stack 内有垂直互连，stack 与计算 die 可通过中介层或桥连接。 |

这些维度可以同时存在。例如，HBM 的 DRAM die 可以堆叠，再与计算 die 通过封装内互连连接；模块上也可以装有多 die 封装。接口家族、模块形态、die 组织与系统拓扑应分别记录。

更短的互连可能有助于电气设计，但可用速率、能耗和信号完整性仍取决于驱动、负载、走线、封装和工作状态。热、供电、测试与可维护性也需要在具体系统中评估。

## 一句话理解

系统集成要同时描述器件、物理连接和可维护边界，不能用一个“封装类型”概括全部关系。

## 建模启示

按需记录器件接口和配置、模块及连接器、封装内 die 组成、物理互连、热与供电边界。区分测量值、布局估计和未知值。性能模型还应记录共享资源和流量；不能只依据互连距离推导带宽或单位能耗。
